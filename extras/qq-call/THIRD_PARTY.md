# 第三方组件

本目录只包含我们自己的 Python/PowerShell 编排代码，不随仓库分发下列组件。使用时请遵守各自许可证和条款。

| 组件 | 用途 | 说明 |
|---|---|---|
| [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | 本地 ASR 运行时 | Apache-2.0 |
| SenseVoice ONNX 模型 | 本地语音识别 | 按模型发布方许可证使用；仓库不附带模型 |
| [VB-CABLE](https://vb-audio.com/Cable/) | 虚拟声卡 | VB-Audio 的授权条款；仓库不附带安装包 |
| [FFmpeg](https://ffmpeg.org/) | 音频转码 | LGPL/GPL，取决于构建；仓库不附带二进制 |
| [AudioDeviceCmdlets](https://github.com/frgnca/AudioDeviceCmdlets) | 切换 Windows 默认录音设备 | MIT；需自行下载 DLL |
| [edge-tts](https://github.com/rany2/edge-tts) | Edge 在线 TTS | 按上游许可证使用 |
| Breeze TTS | 在线/本地 TTS | 按 Breeze 上游条款使用；在线版需要自己的 key，模型通常仅限研究/非商业 |
| QQ NT | 通话客户端 | 腾讯软件条款；本目录不使用任何私有服务端 |
