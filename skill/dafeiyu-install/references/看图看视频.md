# 看图、看视频

10-27 在干净账户里实测过：后台网页聊天发图她能说出图里是什么，发 20 秒视频她把画面里的字幕一句不差地念了出来，回复 2–3 秒；QQ 私聊发 14 秒视频，她认出了画面里的工牌（1.8 秒）。本机语音识别 10-27 晚实测（当时是按停顿断句的版本）：Vol.04 开头 20 秒口播几乎一字不差，截图加识别一共 2–3 秒。10-28 0:00 实测切段整认 + 增强版（后台网页聊天）：20 秒口播视频转写 122 字，插件用时 18.8 秒；10 秒的戏曲视频 12.3 秒，她能说出唱的什么。**QQ 私聊、群里 @ 她还没实测新版。** 10-28 下午 QQ 群实测：先发图、再 @ 她问「看图」，她说出了图里的内容（群里看图插件 1.1 秒看完）；群里有人发语音没 @ 她，4 秒转成文字存进上下文，过一会儿有人 @ 她，她接上了语音里说的话。私聊语音还没测。

## 怎么回事（给你看的）

- **看图**：`deepseek-flash` 本来就能看图，配置包导入时会把对话模型的「模型能力」补上图片，再打开群聊插件的看图开关。私聊随便发。群里分两种：@ 她那条里带的图，群聊插件自己看；没 @ 她的图，配置包自带的「群里看图」插件（`astrbot_plugin_dafeiyu_groupimage`，导入 `plugins` 那块就装）先用识图模型写成一行「[图片：……]」再交给群聊插件，所以先发图、再 @ 她问也答得上来（群聊插件原本靠 AstrBot 旧版的平台记忆保留没 @ 她的图，4.29 起那条路不通，图直接丢了）。一条消息最多看 3 张，同一张图一小时内只看一次。一张图不到半分钱，群里图多会多花一点；嫌花钱在后台插件设置里把它关掉，就回到只看 @ 她带的图。群聊插件的「触发关键词」配置包没填，叫名字不算 @；填了名字她在群里会回得更勤。
- **看视频**：DeepSeek 看不了视频。配置包里的「大肥鱼看视频」插件用 ffmpeg 从视频里均匀截几张画面（大约每 5 秒一张，3–6 张，只看前 3 分钟）交给她看，再用本机语音识别把视频里说的话转成文字一起交给她。本机识别是 sherpa-onnx 的现成程序加 SenseVoice 模型（阿里开源，中英日韩粤都认），在观众电脑的 CPU 上算，十几秒的话一两秒认完，不花钱、不用注册。声音每 15 秒切一段整段认，不按停顿断句（带伴奏的歌按停顿一句都切不出来）。
- **增强版**（问 ③ 5C）：再装一个 Fun-ASR-Nano（阿里开源，多约 840 MB）。10-27 用 16 段方言、歌曲、难念的普通话比过四个模型（`skill-draft/识别模型对比-1027.md`）：湖南话、闽南话、上海话和歌词它认得明显更准；粤语、四川话、天津话、河南话 SenseVoice 已经够好；代价是慢：每次先花约 6 秒把模型读进内存，再按时长的三成左右认（测试机 i9 笔记本），所以十几秒的短视频也要多等 10 秒左右，一分钟的多等半分钟左右；SenseVoice 一两秒就完。装了增强版插件先用它，没认出字或出错再退回 SenseVoice。私聊都看，群里 @ 她才看。一段一两分钟的视频大约 1–2 分钱（截图按图收钱，听声音不花钱）。
- **听 QQ 语音**：同一个插件、同一套识别。私聊、群里发来的语音（QQ 的 silk 格式先用 AstrBot 自带的工具转成 wav）先转成一行「[语音：……]」，排在群聊插件和对话模型前面，她就当对方打了这行字。几秒的语音 3–4 秒认完（10-28 测试机）。群里的语音没法 @ 她，转成字以后照普通消息走群聊插件的概率；没接也会存进上下文。只认语音里说的话，语气、哭笑这些听不出来。所以「听语音」跟着看视频一起装：问 ③ 选 5B、5C 才有。
- 没装本机识别的（老版本升级上来的），记忆选了在线（硅基流动）就用那把 key 转写；都没有她只看画面，会老实说没听到声音。
- 截的画面只给那一轮看、不进聊天记录，之后每轮不会重复收钱。代价：追问画面细节她会说「当时没看清」。想让她记住画面，在后台插件设置里打开 `keep_frames`。
- 她会唱歌这件事不在承诺里（配置包 2.0 起默认不装唱歌插件）。

## 问 ③ 里怎么写

看图默认开，不单列成选项，在第 4 项后面带一句。看视频默认关，列成第 5 项（问法模板见 SKILL.md 第 1 步）。对话模型不是 `deepseek-flash`（体检 `chatSeesImages` 为假）的，把看图那句换成「她现在用的模型看不了图，要换成 deepseek-flash 吗」。

## 他选了看视频

1. 装 ffmpeg（优先阿里云 PyPI 的 imageio-ffmpeg 0.6.0 wheel，约 30 MB，内含 ffmpeg 7.1；失败再下 GitHub 的 9.0.2 essentials 包；电脑上已经有的会直接用）。插件只调用 ffmpeg，不需要 ffprobe。用时看网速：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\install-ffmpeg.ps1" -Dir <工作目录>
   ```

   **成功**：「ffmpeg 能用：ffmpeg version …」，路径记在 `<工作目录>\ffmpeg-path.txt`。
   **失败先查**：阿里云和 GitHub 备用地址都失败，先查网络环境；中断后重跑会续传，地址不支持续传才清掉半截重下。「文件校验不对」可能是错误页或文件损坏，脚本会删掉重下。

2. 装本机语音识别：sherpa-onnx v1.13.8 程序原包约 22 MB，从 GitHub 加速列表依次试，保留配套的两个 DLL；SenseVoice 2025-09-09 模型优先从 hf-mirror 逐个下模型、tokens 和中文样例，模型约 226 MB，分别核 SHA256。失败退回 GitHub 同版模型压缩包，约 158 MB。选 5C 的加 `-Plus` 装增强版，大小以脚本提示为准；GitHub 大模型包会先给每个地址测速 6 秒，再按顺序下载，测速时限不是下载时限。用时看网速，下载中每 15 秒报进度。先装了 B 后来想要增强版的，加 `-Plus` 重跑就行，已经有的不重下：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\install-asr.ps1" -Dir <工作目录> [-Plus]
   ```

   **成功**：「语音识别能用，试认样例：开放时间早上九点至下午五点」（样例开头没留空白，偶尔会丢掉第一个字，插件认视频时会先垫半秒，不影响），带 `-Plus` 的还有一行「增强版也能用，试认样例：……」；文件夹记在 `<工作目录>\asr-path.txt`（就是 `<工作目录>\asr`，增强版在它下面的 `funasr-nano`）。
   **失败先查**：下载同 ffmpeg；「识别程序跑了但没认出字」把它打出的最后几行原样看一下，多半是杀毒软件拦了 exe 或 dll，或者内存不够（增强版认的时候要多占 1 GB 多内存）。

3. `answers.json` 里加三项，然后照常导入（`导入配置包.md`）：

   ```json
   "video": "1",
   "ffmpeg_path": "<工作目录>\\ffmpeg\\bin\\ffmpeg.exe",
   "asr_dir": "<工作目录>\\asr"
   ```

   **成功**：结果列表里有「✔ 插件 astrbot_plugin_dafeiyu_video」。

## 验收

- 私聊发一张图，问「图里是什么」。
- 选了群的：群里 @ 她发一张图问是什么；再不 @ 发一张，接着 @ 她问「刚才那张图是什么」，两次都该答得上来。日志里第二张那条有 `[群里的图] 看了 X 秒：……`。
- 选了看视频的：私聊发一条 QQ 语音，她应该接着语音的内容回；日志里有 `[dafeiyu_video] 听了一条语音（本机识别（SenseVoice））：N 字`。
- 选了看视频的：私聊发一段 10–30 秒、有人说话的视频，问「视频里说了啥」。日志里（`astr_setup.py ... logs 40`）应该有一行 `[dafeiyu_video] 看了一段 0:xx 的视频：N 张画面，本机识别（SenseVoice）转写 M 字`，装了增强版的括号里是「增强版」。

**失败先查**：
- 她说「看不了视频（电脑上没装 ffmpeg）」：插件设置里的 `ffmpeg_path` 不对，或者 ffmpeg 被删了，重跑 `install-ffmpeg.ps1` 再导入。
- 日志里没有 `[dafeiyu_video]` 那行：插件没装上（导入时 `video` 没填 1），或者群里没 @ 她。
- 日志里是「没转写」，她说没听到声音：插件设置里的 `asr_dir` 不对（文件夹里要有 `sherpa-onnx-offline.exe`、`model.int8.onnx`、`tokens.txt`；10-27 晚之前装的是断句版 `sherpa-onnx-vad-with-offline-asr.exe`，新插件不认），重跑 `install-asr.ps1` 再导入。
- 日志里是「本机识别（…）没认出字」：视频里多半只有音乐或杂音，她会说没听出有人说话，正常。
- 装了增强版但括号里是「SenseVoice（增强版出错：…）」：照报错查，`funasr-nano` 里缺文件就加 `-Plus` 重跑；括号里是「增强版没认出字」是它退回 SenseVoice 了，正常。
- 日志里有「声音转文字没成功（本机识别）」：后面跟的是识别程序的报错，照着查。
- 发图她说看不到：`astr_setup.py ... status` 看默认模型是不是 `deepseek-flash`。

## 不用的路线（为什么）

- 把识别程序换成 `sherpa_onnx_bin` wheel：这个 Windows wheel 能跑 `--help`，实际识别会崩溃。继续用 GitHub 带配套 DLL 的原包，必须认出样例里的文字才算能用。
- 听声音用 Python 包（funasr、faster-whisper、pip 装 sherpa-onnx）：要往 AstrBot 的 Python 里装包，装坏了连 AstrBot 一起起不来，也卸不干净；用现成 exe 跟 ffmpeg 一个路子，删掉文件夹就卸干净。
- 听声音用 whisper：中文常出繁体、对着音乐和静音会编字；SenseVoice 中文准、快。
- 按停顿断句（silero VAD）再认：带伴奏的说唱一段都切不出来，结果一个字没有；说话一直说到视频结尾，最后一句会丢。改成每 15 秒切一段整段认（10 秒长歌最好、25 秒电话杂音最好，平均差不多）。
- 增强版用 Qwen3-ASR：难念的普通话会编（吐出一段英文，或者只吐一个 system）；FireRedASR2：比 SenseVoice 好一点，但不如 Fun-ASR-Nano。听歌识曲不做，那是另一回事。
- 让识别程序自动判语言：短句容易判成粤语（「锻炼出来」认成「对炼出嚟」）；固定按普通话认，英文和粤语样例照样认得对。

- 现成插件 `astrbot_plugin_videos_analysis`（79 星，AGPL-3.0）：太重，要装 playwright，默认还会装 Chrome，一大串抖音、B 站功能要关。
- 能直接看视频的模型（豆包视觉、通义、MiMo-omni、Gemini）：都要另外开通，AstrBot 也不会把视频直接交给它们，还得配插件。
