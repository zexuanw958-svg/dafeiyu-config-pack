# 语音 B：本机 Breeze TTS 2（导入时 voice = 4）

开源语音模型，在他自己的显卡上算，不花钱；声音可以一句话「捏」出来，也能拿录音克隆。配置包 `8c01b03` 起自带安装和做声音的工具。

**许可（要跟他说）**：程序是 Apache-2.0；模型和用它生成的声音只许研究和非商业使用。「自己玩没问题，用它做出来的声音别拿去商用。」

## 能不能跑（看第 0 步探测结果）

| 显卡 | 怎么办 |
|---|---|
| 显存 ≥ 6 GB | 大模型 q8_0，下载 3.3 GB |
| 3–6 GB | 小模型 q4_k，下载 2.4 GB |
| < 3 GB 或没独显 | 退到 CPU，一句十几秒以上。能用，不推荐，建议他选豆包 |

实测只有 RTX 4060 8 GB（N 卡）和帮人装过的一台 RTX 5080 16 GB。A 卡、Intel 核显（都走 Vulkan）、纯 CPU 待实测。4060 上大模型 9 秒的话 6.7 秒合成完，小模型 6.4 秒的话 4.4 秒。开着时常驻占几 GB 显存（4060 上约 4 GB，5080 那台约 6 GB），他玩大游戏时会抢显存，跟他说一声：打游戏前在工作台点「打游戏模式」，打完点「打完了，恢复」（`记忆.md`「对电脑的影响、打游戏」）。

## 1 安装

配置包里的安装脚本已经做好了：看显存挑模型；程序约 71 MB，从 GitHub 下，按 gh.dpik.top → edgeone.gh-proxy.com → hk.gh-proxy.org → gh-proxy.org → GitHub 依次试；模型从 hf-mirror 下，不行再 huggingface.co。下载会保留半截、换源续传，核体积和 SHA256；程序包核 SHA256。连接最多等 12 秒；持续 45 秒低于约 30 KB/s 会判为低速，重试后仍失败才换源，不是 45 秒内一定换源。每 15 秒报已下体积和剩余时间；总大小未知时只报体积和速度。随后写启动脚本和桌面快捷方式「启动Breeze语音」，可选开机自启，装完启动并等服务好。

你来跑：

```powershell
'' | powershell -NoProfile -ExecutionPolicy Bypass -File "<工作目录>\dafeiyu-config-pack\tools\breeze\install_breeze.ps1" -Dir "<工作目录>\breeze-tts"
```

`-Dir` 跳过了「装到哪」那一问；最后还会问「开机自动启动吗」（`Read-Host`），前面管道喂的空行就是「要」（10-27 DSH 实测能答上）。下载量按上表选中的模型加程序包计算，用时看网速；开始下载后照脚本进度转述，下断了重跑会接着下。

**成功**：`GET http://127.0.0.1:8137/v1/voices` 返回 200；任务栏里有个最小化的黑窗口「Breeze TTS」。
**失败先查**：
- 路径带中文或空格：脚本直接拒绝，换全英文路径。
- 模型下不动：脚本先试 hf-mirror，再试 huggingface.co；两个都失败再查网络环境，未下完的文件留着重跑。报 Range／curl 33 表示地址不支持续传，脚本会清掉半截在同源重下；体积或 SHA256 不对会删掉换源，空间不足就先腾空间或换盘。你要是改用 `huggingface_hub` 或命令行工具自己下，先设 `HF_HUB_DISABLE_XET=1`，不然走镜像会 401。
- 等了 3 分钟服务没起来：看那个黑窗口的报错（多半是显卡驱动太旧不支持 Vulkan），让他截图给你。

## 2 做声音（存成 `dafeiyu`）

两种做法，先推荐第一种。做声音也可以让他自己双击 `做声音.bat`（一问一答），下面是你直接调接口的做法，效果一样。

**A. 一句话捏一个声音（不用准备录音）**

1. 描述：默认用配置包 `voice.breeze.persona`（「一个憨萌软糯的小女生，声音甜甜的、有点奶……」）；换了角色就按角色写一句，问他想要什么感觉。
2. 出三个候选：各 `POST /v1/audio/speech`，body `{"input": <试音台词>, "instructions": <描述>, "cfg_scale": 4, "seed": <随机>, "response_format": "pcm"}`，返回 24 kHz、单声道、16 位 PCM，写成 wav 存到 `<配置包>\voice\breeze\候选1.wav` 等。试音台词用 `make_voice.py` 里的 `DESIGN_TEXT`。
3. 一个个 `Start-Process` 放给他听，问「喜欢第几个？都不喜欢我再出三个，或者换个描述」。
4. 存：`POST /v1/voices`，multipart：`ref_audio`（选中的 wav）、`ref_text`（就是试音台词）、`name` = `dafeiyu`、`description`（描述）。
5. 试听：`POST /v1/audio/speech`，`{"model": "tts-1", "voice": "dafeiyu", "input": <一句台词>}`，放给他听。

4060 上出三个候选约 24 秒。

**B. 拿一段录音克隆**

他给什么录音就用什么，不追问是谁的声音、不劝他换。开头那句许可照说：用它做出来的声音别拿去商用。想让她像某个角色，克隆角色的录音通常比一句话捏更像。

1. 让他准备 5–15 秒、只有一个人说话、没有背景音乐的录音，把路径告诉你（不用他上传到对话里）。
2. 要录音里的原话一字不差。他打不出来的，你用 faster-whisper 转一遍再让他核（转写工具装单独的虚拟环境，别装进 AstrBot 的；faster-whisper 1.2.1 自带的解码和 PyAV 19 不兼容，要自己解码，见坑）。
3. 不是 wav 就用 ffmpeg 转成 24 kHz 单声道（没有 ffmpeg：`winget install Gyan.FFmpeg`，会弹 UAC，叫人）。
4. 质量好一点的做法（帮人装的那单就这么做的）：在静音处截 8–15 秒整句，音量拉到 -3 dBFS，截三四段语气不同的各出一个候选念同一句话，让他挑。
5. 存法同 A 的第 4 步，`ref_text` 填原话。拿 mp3 克隆在 4060 上约 6 秒。

真人录音克隆的效果没系统测过（10-27 测的是 Breeze 自己生成的音），待实测。

**成功**：`GET /v1/voices` 里有 `dafeiyu`，试听他满意。
**以后换声音**：同名再存一次就覆盖，马上生效，不用重新导入。

## 3 导入

回答文件 `"voice": "4"`，不用 key。导入工具会先查 Breeze 在不在、`dafeiyu` 做没做，再建 `openai_tts_api` 提供商（`api_base` = `http://127.0.0.1:8137/v1`），并把之前开着的豆包语音关掉（不然两种声音混着发）。

**提醒他**：用的时候 Breeze 得开着，任务栏那个黑窗口别关；关了就双击桌面的「启动Breeze语音」。
