# 语音 B：本机 Breeze TTS 2（导入时 voice = 4）

开源语音模型，在他自己的显卡上算，不花钱；声音可以一句话「捏」出来，也能拿录音克隆。配置包 `8c01b03` 起自带安装和做声音的工具。

**许可（要跟他说）**：程序是 Apache-2.0；模型和用它生成的声音只许研究和非商业使用。「自己玩没问题，用它做出来的声音别拿去商用。」

## 能不能跑（看第 0 步探测结果）

| 显卡 | 怎么办 |
|---|---|
| 显存 ≥ 6 GB | 大模型 q8_0，下载 3.3 GB |
| 3–6 GB | 小模型 q4_k，下载 2.4 GB |
| < 3 GB 或没独显 | 退到 CPU，一句十几秒以上。能用，不推荐，建议他选 Breeze 在线版（见 `语音-Breeze在线.md`） |

实测只有 RTX 4060 8 GB（N 卡）和帮人装过的一台 RTX 5080 16 GB。A 卡、Intel 核显（都走 Vulkan）、纯 CPU 待实测。4060 上大模型 9 秒的话 6.7 秒合成完，小模型 6.4 秒的话 4.4 秒。开着时常驻占几 GB 显存（4060 上约 4 GB，5080 那台约 6 GB），他玩大游戏时会抢显存，跟他说一声：打游戏前在工作台点「打游戏模式」，打完点「打完了，恢复」（`记忆.md`「对电脑的影响、打游戏」）。

## 1 安装

配置包里的安装脚本已经做好了：看显存挑模型；程序约 71 MB，从 GitHub 下，按 gh.dpik.top → edgeone.gh-proxy.com → hk.gh-proxy.org → gh-proxy.org → GitHub 依次试；模型从 hf-mirror 下，不行再 huggingface.co。下载会保留半截、换源续传，核体积和 SHA256；程序包核 SHA256。连接最多等 12 秒；持续 45 秒低于约 30 KB/s 会判为低速，重试后仍失败才换源，不是 45 秒内一定换源。每 15 秒报已下体积和剩余时间；总大小未知时只报体积和速度。随后写启动脚本和桌面快捷方式「启动Breeze语音」，可选开机自启，装完启动并等服务好。

你来跑：

```powershell
'' | powershell -NoProfile -ExecutionPolicy Bypass -File "<工作目录>\dafeiyu-config-pack\tools\breeze\install_breeze.ps1" -Dir "<工作目录>\breeze-tts"
```

`-Dir` 跳过了「装到哪」那一问；最后还会问「开机自动启动吗」（`Read-Host`），前面管道喂的空行就是「要」（10-27 DSH 实测能答上）。下载量按上表选中的模型加程序包计算，用时看网速；开始下载后照脚本进度转述，下断了重跑会接着下。

**成功**：`GET http://127.0.0.1:8137/v1/voices` 返回 200；任务栏里有个最小化的黑窗口「Breeze TTS」。
**失败先查**：
- 路径带中文或空格：脚本直接拒绝，换全英文路径。
- 模型下不动：脚本先试 hf-mirror，再试 huggingface.co；两个都失败再查网络环境，未下完的文件留着重跑。报 Range／curl 33 表示地址不支持续传，脚本会清掉半截在同源重下；体积或 SHA256 不对会删掉换源，空间不足就先腾空间或换盘。你要是改用 `huggingface_hub` 或命令行工具自己下，先设 `HF_HUB_DISABLE_XET=1`，不然走镜像会 401。
- 等了 3 分钟服务没起来：看那个黑窗口的报错（多半是显卡驱动太旧不支持 Vulkan），让他截图给你。

## 2 做声音（存成 `dafeiyu`）

两种做法，先推荐第一种。两种都是**先试听，他点头了才存**。可以让他自己双击 `做声音.bat`（一问一答），也可以你来跑，效果一样。你来跑就用 `make_voice.py` 的三个命令，它们不弹播放器、不问问题，结果打在屏幕上：

```powershell
$mv = "<配置包>\tools\breeze\make_voice.py"   # <配置包> = <工作目录>\dafeiyu-config-pack
& "<py>" -X utf8 $mv prep "<录音>" [--pick N]          # 克隆用：截一段、转写
& "<py>" -X utf8 $mv preview "<wav>" "<原话>"         # 试听：出 <配置包>\voice\breeze\试听.wav，不存声音
& "<py>" -X utf8 $mv save "<wav>" "<原话>" [--original "<录音>"]   # 存成 dafeiyu，参考音和原话留底
```

`<py>` 同 `基础-AstrBot和DeepSeek.md` 开头（`<工作目录>\uv\tools\astrbot\Scripts\python.exe`）。Breeze 正忙（她在 QQ 里念语音）时会自己等，最多等 2 分钟。

**为什么要先试听**：QQ 里她每句话都是拿存下的那段参考音、按 cfg 1、种子 42 克隆出来的，描述不再起作用。`preview` 就是照这个念一句 `TRY_TEXT`，听到的就是她以后在 QQ 里的样子。

**A. 一段话捏一个声音（不用准备录音）**

1. 描述：默认用配置包的 `voice.breeze.persona`（大肥鱼那段）；换了角色，问他想要什么感觉，照 `角色包.md` 第 3 节写一句带情绪的短描述。
2. 出三个候选：各 `POST /v1/audio/speech`，body `{"input": <试音台词>, "instructions": <描述>, "cfg_scale": 3, "seed": <随机>, "response_format": "pcm"}`，返回 24 kHz、单声道、16 位 PCM，写成 wav 存到 `<配置包>\voice\breeze\候选1.wav` 等。试音台词用 `make_voice.py` 里的 `DESIGN_TEXT`。cfg 用 3：用 4 时，描述里的每个词都会被当真，换个种子差得也更多（10-28 实测）。
3. 一个个 `Start-Process` 放给他听，问「喜欢第几个？都不喜欢我再出三个，或者换个描述」。挑的时候留意停顿处干不干净，有没有气声、嗡声：存下的这条会被每句话照着克隆。大概每 5–7 个候选里会出一个停顿处有轻微嗡声的。
4. 试听他挑的那个：`preview <候选wav> "<试音台词>"`，放 `试听.wav` 给他听。
5. 他满意了再存：`save <候选wav> "<试音台词>"`。

4060 上出三个候选约 24 秒，试听一句约 5 秒。

**B. 拿一段录音克隆**

他给什么录音就用什么，不追问是谁的声音、不劝他换。开头那句许可照说：用它做出来的声音别拿去商用。想让她像某个角色，克隆角色的录音通常比捏出来的更像。

1. 录音要只有一个人说话，没有背景音乐、回声和风扇声，这些都会被一起复制。有配乐的（官方 PV、动画片段），先让他用 UVR（Ultimate Vocal Remover，免费）去伴奏，再用导出的人声那轨。录音长一点没关系，工具会自己截。
2. 截一段并转写：`prep "<录音>"`。它会在停顿处截一段 8–15 秒的整句，把音量拉到 -3 dB，存成 `<配置包>\voice\breeze\克隆-参考.wav`；再用本机 SenseVoice 把原话转出来，按停顿补上逗号。同时列出其他能截的段，换段用 `--pick 2`。
   - mp3、m4a 和视频要用 ffmpeg 读。它会先找工作目录里的那份（`install-ffmpeg.ps1` 装的，记在 `ffmpeg-path.txt`）。没有的话先跑 `install-ffmpeg.ps1`，别用 winget。
   - 转写用的是看视频那套本机识别（`install-asr.ps1` 装的，记在 `asr-path.txt`）。没装的话就让他自己打原话；只为做声音，不用专门装。
3. 把截的那段放给他听，转出来的原话给他核对。Breeze 要原话一字不差、带标点；错一两个字还能用，但会差一点。
4. 试听：`preview "<配置包>\voice\breeze\克隆-参考.wav" "<原话>"`。不满意就换一段（`prep ... --pick N`）或者换一段录音。
5. 存：`save "<配置包>\voice\breeze\克隆-参考.wav" "<原话>" --original "<录音>"`。原录音不超过 50 MB 的会拷一份留底，更大的（比如整段视频）只记下它在哪。

10-28 用真人录音实测（cfg 1）：干净的 6–11 秒录音，克隆出来跟原声很接近；只有 2 秒的话，像的程度会下降；带背景音乐或者风扇声、回声的，这些声音会出现在停顿里。4060 上截段加转写约 2 秒，试听一句约 4 秒。

**成功**：`GET /v1/voices` 里有 `dafeiyu`，他听过试听、满意。
**以后换声音**：同名再存一次就覆盖，马上生效，不用重新导入。上一份参考音会改名留着。
**换了 Breeze 模型**：存过的声音会失效。拿 `<配置包>\voice\breeze\dafeiyu-参考.wav` 和同名 `.txt` 里的原话重新 `save` 一次。`voice\breeze\` 不在仓库里，升级 Skill 换配置包时要把它拷到新包里。

## 3 导入

回答文件 `"voice": "4"`，不用 key。导入工具会先查 Breeze 在不在、`dafeiyu` 做没做，再建 `openai_tts_api` 提供商（`api_base` = `http://127.0.0.1:8137/v1`），并把之前开着的豆包语音关掉（不然两种声音混着发）。

**成功**：导入工具结果里语音那一项打勾；聊到她回一条语音以后，问她「你刚才那条语音说的啥」，她能说出内容，而不是「我只会打字」。说不出来，看后台插件列表里 `astrbot_plugin_dafeiyu_clean` 是不是 v0.2.0 以上。

**提醒他**：用的时候 Breeze 得开着，任务栏那个黑窗口别关；关了就双击桌面的「启动Breeze语音」。
