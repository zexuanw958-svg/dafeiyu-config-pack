# 坑（先查这里）

别的文件里写「坑 N」指的就是这里的编号。1–9 是帮人部署时踩过的，10 以后是观众评论区和 Agent 代劳测试里碰到的。

## 部署里踩过的

1. **没先问角色就装**：先装通用大肥鱼再改成他的角色，人设、表情包、声音全白做一轮。第 1 步一次问清。
2. **放在他电脑上的说明、网页、提示用泽轩第一人称、口语**（「截图发我」），不写客服腔，也不写第三人称「告诉泽轩」。
3. **大文件用现成下载器**：已接入公共下载器的 Skill 文件用 `common.ps1` 的 `Get-File`，Breeze 用自己的下载函数。国内源优先；普通 GitHub 文件按列表依次试，Ollama 安装包、GitHub 大模型包先测速。连接最多等 12 秒，持续 45 秒低于约 30 KB/s 会判为低速，重试后仍失败才换源；文件下载不设总时限，每 15 秒报进度。中断后重跑会续传；Range／curl 33 表示地址不支持续传，脚本会清掉半截同源重下；体积或 SHA256 不对会删掉换源。报空间不足先腾空间或换盘：已知文件大小时至少留两倍，大小未知时只能先按最小体积检查，读到总大小后再核。
4. **NapCat 终端里的字符二维码扫不出来**，第一张还常过期。用二维码图片 + 每 3 秒刷新的 `qr.html`，过期就重启 NapCat。
5. **表情包仓库 manifest 写的版本标签可能不存在**（爱弥斯那套写 v1.0.0，仓库只有 main），从 GitHub 装时 `ref` 填 `main`。
6. **他在网页上改了后台密码，`backend.txt` 就过期了**，你所有接口都登不上。改密码放最后；改完让他写回文件。
7. **AstrBot 初始密码里有 O/0 这种难分的字符**，从截图读容易读错。让他复制原文，或者几种变体都试。
8. **Ollama 安装包不会自己加开机启动**，要手动在启动文件夹放快捷方式。
9. **群里不发表情包**：meme_manager 的 `generation.trigger.scope` 默认 `only_chat_llm`，跳过群聊插件代发的回复。改成 `chat_and_plugin_llm`；配置包 `7121c0c` 起导入时自动改。

## 观众真实卡点（10-26 评论区）

10. **双击 `导入大肥鱼.bat` 只显示 `Press any key to continue` 就退出**：旧版 bat 只在默认目录找 AstrBot 的 Python，启动器「高级」里改过数据目录就找不到，退到 PATH 里多半是 WindowsApps 那个应用商店空壳 python，什么都不输出就退了。`554db41` 修了，换新包；你代劳时本来就不双击 bat，用回答文件。
11. **NapCat「移动versions目录失败：拒绝访问」/ 一直解压失败**：上次失败留下的 `Shell\versions` 让每次重试都卡住。删整个 `NapCat.<数字>.Shell` 再跑，已下好的 `QQ.exe`、`NapCat.Shell.zip` 留着。
12. **找不到 NapCat 后台地址**：在启动窗口里二维码上面那一行 `WebUi User Panel Url: http://127.0.0.1:6099/webui?token=…`，被二维码顶上去了。
13. **AstrBot 的 Python 下不动 / 报 403**：先分清安装路线。命令行版用 `install-astrbot.ps1`，先单独装受管 Python，按 npmmirror → 南大 → GitHub 加速列表试；Python 好了再按阿里云 → 清华 → 腾讯 → 华为 → PyPI 官方装依赖。启动器版才按它的「中国大陆一键加速」开关重试；要改观众现有的网络设置，先说明再问。
14. **语音报 `45000030 requested resource not granted`**：应用没领 Seed Audio 1.0 试用，或 APP ID 是别的应用的。
15. **`napcat.bat` 找不到**：Shell 文件夹在 `NapCatInstaller.exe` 旁边；隐藏扩展名时显示成 `napcat`；文件夹或 `napcat` 不在说明安装没走完。

## Agent 代劳时碰到的

16. **DSH 沙箱不让往配置包文件夹写回答文件**（10-25 P2）：它自己改写到工作区也成功了。回答文件放 `<工作目录>` 下最省事。
17. **权限确认会弹好几次**（P4 叫人 3 次，全是权限和确认）。第一次就跟他说「看到允许就点允许，有『本次都允许』选它」。
18. **弹 Windows 防火墙框问要不要放行联网**：WorkBuddy（10-25 点了拒绝照样跑通）；NapCat 自带的 QQ 每换一个文件夹第一次启动也弹一次（10-28 测试机上见到，标题「是否要允许公共网络和专用网络访问此应用？」，点「显示更多」能看到是哪个 qq.exe）。点哪个都行，建议「取消」：它只管别人从外面连进来，QQ 连腾讯服务器是往外连、连 AstrBot 是本机连，都不受影响（按原理，NapCat 这边点取消后的聊天没专门测）。别因为这个停住。
19. **打印凭证文件时把密码打出来了**（10-25 事故：文件里是中文冒号，按英文冒号切没切开，整行打印）。看凭证文件只打印「有没有这个键」，切分时中英文冒号都认。
20. **PowerShell 里中文显示成问号**：多半是控制台编码，原始字节没坏。先 `[Console]::OutputEncoding = [Text.Encoding]::UTF8`。
21. **`Set-Clipboard` 会顶掉他剪贴板里的东西**（帮人装时对方拷的表情包仓库名被我们的命令顶掉了）。用剪贴板传 token 前先说一声。
22. **带中文的 ps1 要存 UTF-8 BOM**；`$变量?` 写成 `${变量}?`。
23. **DSH 默认「工作区可写」的沙盒里，curl 下载全挂（`SEC_E_NO_CREDENTIALS`）、WMI 拒绝访问、`C:\dafeiyu` 写不进去**（10-27）。体检能在沙盒里跑（`probe.ps1` 有备用读法），安装脚本要完全访问，见 SKILL.md「你自己的权限」。别为了躲沙盒把东西装到桌面。
24. **Ollama 安装包用 `/S` 静默装会卡住**：它是 Inno Setup，不认 `/S`，停在「Install」按钮上等人点（10-27 卡了 10 分钟）。用 `install-ollama.ps1`（`/VERYSILENT`）。
25. **杀毒软件弹「××试图开机启动 阻止/允许」**（10-27 测试机的腾讯电脑管家、火绒）：`finish.ps1` 放进启动文件夹的快捷方式可能也会被拦（没确认）。弹了就让他点「允许」；重启后她没自己上线，先查启动项是不是被拦了。
35. **计划任务直接跑 `cmd` 会被 Windows Terminal 接管，弹一个大黑窗口盖在最上面**（10-28 桌面版实测「Dafeiyu-AstrBot (do not close)」），录屏挡画面，他一关她就下线。`Start-Detached` 已改成 `conhost --headless` 起，不出窗口；看状态用工作台。开机自启那条照旧是最小化窗口。
36. **装 AstrBot 时端口被别的目录那套占着**（另装一套、换了盘重装）：以前脚本只说「先不重复启动」，接着等到端口在听就报「起来了」，其实那是旧的。现在 `install-astrbot.ps1` 会查占端口的程序在哪：不在这个工作目录就停下，叫你换端口（`-Port 6285`）或先 `stop-instance.ps1` 关旧的。
37. **另装一套时别自己拷表情包文件夹**：拷进 `plugin_data\meme_manager` 再重启，插件不认、会删掉重下（10-28 桌面版 DSH 这么干，白等 460 MB）。回答文件填 `meme_copy_from`，导入工具走插件的分片导入接口，462 MB 24 秒导好。表情包插件单次请求有大小上限，一次传 462 MB 会被断开（`ConnectionAbortedError`），本地导入一律 8 MB 一片。
26. **配置包是小 zip**，用 `Get-GitHubFile` 时 `-MinBytes` 填 `100000`，别填 1 MB；下好以后还要确认能解压出 `tools\import_dafeiyu.py`。

## QQ 和网络

27. **同一个 QQ 号不能同时接两个协议端**（NapCat 和 SnowLuma，或者两套 NapCat），会互相挤下线。换协议端前先停旧的。
28. **QQ 风控**：新注册的小号、异地、频繁登录、群里话太多都容易被踢或弹「账号存在安全风险」。只能他在手机 QQ 上按提示恢复。云服务器机房 IP 更容易被踢（之前一单云服务器两小时被踢两次），所以这个 Skill 只管家用电脑。
29. **`Login Error ErrCode 5` 以后不再出新码**：重启 NapCat。二维码 2 分钟过期。
38. **扫码登上了，重启成快速登录时报「你的用户身份已失效，为保证账号安全，请你重新登录」**（10-28 测试机，扫完约 20 分钟才重启），NapCat 自己出新码。让他再扫一次，扫完重跑 `connect-napcat.ps1`：它认出跑着的已经是快速登录那套，不再重启，只等连上 AstrBot。原因没查清，小号最近在好几台机器上登过，可能有关。
30. **假在线**：NapCat 和网页显示在线但收不到消息，看 `napcat.log` 最后一条「接收 <-」的时间。
31. **Hugging Face 新的 Xet 下载走镜像会 401**：用 `huggingface_hub` 一类工具时先设 `HF_HUB_DISABLE_XET=1`（配置包的 Breeze 脚本用 curl 直链，不受影响）。
32. **faster-whisper 1.2.1 自带的 `decode_audio` 和 PyAV 19 不兼容**（`metadata_errors` 参数），转写要自己解码；转写工具装单独的虚拟环境，不碰 AstrBot 的。

## 还没验证的担心（待实测）

33. 用户名带中文、工作目录带中文，AstrBot / NapCat / Ollama 会不会出问题。Breeze 脚本已知直接拒绝中文路径。现在一律按保守做法用全英文路径。
34. 工作目录所在盘空间不够：整套最多约 10 GB，留 15 GB。
