# 第 8 步：开机自启、掉线自救、桌面说明

家用电脑用「启动文件夹」放快捷方式就够了（他登录 Windows 时启动）。云服务器那种要断开远程也不停的，才用 S4U 计划任务（之前帮人装到云服务器的一单），这里不用。

## 8.1 开机自启和掉线自救（一个脚本）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\finish.ps1" -Dir <工作目录>
```

它做的事：
1. 大脑仍按原来的装法自启。登 QQ 的程序走隐藏的 `relogin-qq.ps1 -Autostart`：先等网络和大脑，再起 NapCat。实例还没开就一直安静等着，不弹报错窗口；大脑起来后试快速登录，失败会重试三次，三次都不行、而且本轮确实出了新二维码，才打开 `扫码登录.html`。连上用的是这个工作目录的协议端连接，不把别的实例当成她在线。SnowLuma 也先等大脑，再在后台起来；桌面 QQ 仍靠它自己的自动启动、自动登录小号，不替他重启。
2. 查当前 Windows 用户的启动文件夹、`HKCU\...\Run`、登录/开机计划任务里有没有另一份 NapCat。只保留这份工作目录的入口，旧快捷方式挪进 `<工作目录>\旧版\开机自启-时间\`，Run 原值和任务 XML 也备份到那里，任务只禁用、不删除。其他 Windows 用户的启动项不碰。工作台「开机自启」有「补上」或「修复」时点一次，也走同一套逻辑；旧版直接起 `start-napcat.cmd` 的入口会换掉。
3. 选本机记忆的放 `Ollama`（`conhost --headless` 只起服务，不开聊天窗口）；Breeze 的开机自启核一下；接了桌宠的再放「大肥鱼-桌宠桥」。
4. 桌面放「大肥鱼掉线-双击扫码」（SnowLuma 叫「大肥鱼掉线-双击重登」）。手动重登也复用同一份脚本，命令行装的大脑没开会先开；启动器装的要在启动器里点实例的「启动」。后台正在等或正在登时，不会再起第二份。扫码最多等 10 分钟。

**成功**：脚本列出放了哪几个开机自启，最后是「桌面放了『大肥鱼掉线-双击扫码』」。脚本提示「start-napcat.cmd 还没带小号」的，回协议端那份把 `connect-napcat.ps1` 跑完。
**失败先查**：桌面不一定在 `C:\Users\<名>\Desktop`（有人的是 `D:\桌面`），脚本用系统记的桌面位置。选 SnowLuma 的，桌面 QQ 的开机自启和自动登录要他自己在 QQ 里点（见 SnowLuma 那份）。

**启动器装的 AstrBot**（「用现有的」路线常见；10-28 群友那台就是）：没有 `start-astrbot.cmd`，开机自启是启动器自己的设置。脚本会查启动器的「开机自启动」开没开（它开了会在注册表 `HKCU\...\Run` 写一项 `AstrBot Launcher`），没开就打出下面这段，你照着带他点，**这一步没做完不算装好**，收尾复述里单列一句：

> 打开 AstrBot 启动器，点最左边的「高级」，在「通用」那一栏打开三个开关：**开机自启动**、**自启动后最小化到托盘**、**退出时保留实例运行状态**。同一栏的「关闭窗口时」保持「最小化到系统托盘」。

「开机自启动」只让启动器自己起来，实例靠「退出时保留实例运行状态」恢复。核过 v0.3.13 和当时的最新版（两者是同一提交）：**只在启动器正常退出时记下在跑的实例**，下次启动尝试恢复一次；失败也会清掉那份记录。源码没有保证 Windows 关机时一定走完保存，不能说「开了这三个就一定自动上线」。

启动器开着、实例没恢复：在启动器里点这个实例的「启动」。工作台左边和「大脑」那项会说清楚，NapCat 在后台等着，不用关掉重开。平时关窗口保持「最小化到系统托盘」；托盘里点退出会把实例一起停掉。

不改启动器数据库，也不从外面另起同一个实例。核过的版本没有公开的命令行、深链接或本地 HTTP 接口让外部启动指定实例，不能拿内部 Tauri 命令当外部接口用。要验开机效果，先跟他说明会短暂下线，再由他自己挑方便的时候重启；不重启时说「入口设好了，实际开机恢复还没验证」。工作台不再拿「大脑启动时间离开机近」当作自动恢复成功的证据。

还有一种「假在线」（之前一单云服务器第二次掉线就是这样）：NapCat 和网页都显示在线，但一条消息也收不到，重启后快速登录报「登录态已失效」。判断办法是看 NapCat 日志里最后一条「接收 <-」是几点。掉线工具和掉线提醒都不查这个（没人发消息时分不清），他说「在线但不回」时你手动看。

## 8.2 掉线提醒

`finish.ps1` 同时放「大肥鱼-掉线提醒」（启动文件夹，登录 Windows 时起来），后台程序 `tools\qq_watch.py`，没窗口。小号掉了就在右下角弹通知，点一下就重新登录。

- 判断：大脑开着但小号没连上，连续 3 分钟；或者 NapCat 日志里最后一件事是被踢下线（`KickedOffLine` 等，被踢时它常常还连着大脑，光看连接看不出来），确认一次就弹。
- 一次掉线最多提醒 3 回：马上、半小时后、两小时后。回到在线就清零。大脑没开、正在重新登、电脑刚睡醒都不算。
- 点通知：本机那套打开 `tools\relogin.cmd`，就是桌面的掉线工具；云端那套打开工作台，自动开始扫码。
- 开关和「试一下」在工作台「操作」页最下面。关着＝`private\qq-watch-off.txt`。状态在 `logs\qq-watch.json`，弹过什么记在 `logs\qq-watch.log`。

Python 用官方便携版（11 MB，放 `tools\python`）：它一直在跑，用 AstrBot 自带的那份会占着文件，升级 AstrBot 时删不掉。下不下来时借 AstrBot 自带的。

**不覆盖**：上面的「假在线」。**只有电脑开着才提醒**：云端那套也是这台电脑盯服务器，每 3 分钟问一次，电脑关着就没人盯了。

通知弹不出来：先让他在工作台点「试一下」。提示系统把通知关了，就是「设置 → 系统 → 通知」的总开关或者「大肥鱼」那一项；专注模式、勿扰开着也看不到（勿扰结束后在通知中心里还有）。

**验收**：工作台点「试一下」弹出通知，点它开得起重登窗口（云端是开工作台）。

**验收**：NapCat 的让他关掉 NapCat 窗口，双击桌面工具，能自己登回来或弹出二维码；SnowLuma 的让他在桌面 QQ 里退出小号，双击「大肥鱼掉线-双击重登」，在 QQ 窗口里点登录。

## 8.3 工作台（代替以前的《大肥鱼怎么用.txt》）

`finish.ps1` 第 3 节做这几件事：把 `scripts\workbench\`（连同里面放图和字体的 `assets\`）整个拷进 `<工作目录>\tools\workbench\`；把 `workbench.ps1`、`common.ps1`、`backend_state.py`、`autostart.ps1`、`relogin-qq.ps1`、`backup.ps1`、`diag.ps1`、`import-pack.ps1` 拷进 `<工作目录>\tools\`（观众删了 Skill，工作台照样能修、能补装、能备份）；写 `tools\workbench.cmd`；在桌面放「大肥鱼工作台」（鲸鱼图标）；再生成一份兜底静态页。打开给他看，让他自己双击桌面「大肥鱼工作台」，或者你在他桌面会话里跑：

```powershell
& "<工作目录>\tools\workbench.cmd"
```

双击以后：`workbench\open.ps1` 找 AstrBot 自带的 Python（命令行装的在 `<工作目录>\uv\tools\astrbot\Scripts\`，启动器装的在实例的 `venv\Scripts\`），用 `pythonw.exe` 起一个本机小服务（`server.py`，只听 127.0.0.1，端口默认 26185，被占就随机），再用 Edge 开一个没有地址栏的小窗口（1100×760 左右，Edge 已经开着时页面自己调大小）。服务已经在跑就只开窗口。窗口关了 3 分钟、又没有在跑的长动作，服务自己退出。找不到 Python 时退回 `workbench.ps1` 的静态页（只能看、不能修）。

页面左边是一张米白卡纸：大肥鱼站在光圈里，头上的话气泡、左上角的小灯、光圈颜色和她的表情都跟着状态变，下面写着现在最要紧的一件事和一个修复按钮。她有三张图：**绿**＝八项都正常（后台在补装、下东西也算，下面多一条进度条；打游戏模式开着也是绿）；**黄**＝还能聊天，有一两个小问题，或者大脑正在起来、小号正在重新登、打游戏模式没恢复完；**红**＝她回不了话（大脑、登 QQ 的程序、DeepSeek 任何一个出问题），或者小问题攒到三个以上。查不到（比如 DeepSeek 余额这会儿没查到）不算问题。三张图的文件在 `workbench\assets\`，文件名只写在 `index.html` 脚本里的 `FACES` 一处；图缺了页面照常能用，卡上只剩光圈、小灯和气泡。右边六页，按 `answers.json` 里他装了什么自动增减：
1. **她的状态**：今天收到几条消息、她回了几次、吃掉多少 token、记住几件事（都从 AstrBot 本机数据库里只读出来，拿不到的格子不显示）；八项检查（大脑、登 QQ 的程序、DeepSeek 余额、记忆、语音、看图看视频、表情包、开机自启）像菜单一样一行一项，出问题的那项下面带修复按钮；接过电脑桌宠的多一项「桌宠」（大肥鱼桥在不在、连不连得上她，带「重开大肥鱼桥」按钮，见 `桌宠.md`）。
2. **一键操作**：重启大脑、重新登 QQ（弹出 `tools\relogin.cmd` 那个窗口）、重启登 QQ 的程序（只停工作目录里的，不碰桌面 QQ）、看最近日志（打过码）、复制求助信息、备份到桌面，还有直达 AstrBot 后台、协议端后台、聊天记录。选了本机语音或本机记忆的，最下面一行是**打游戏模式**的开关：关掉 Breeze 和 Ollama 腾出显卡和内存，她只打字照常聊，打完再点一下开关恢复（左边卡上也有「要打游戏了」「打完了，恢复」）；没恢复就重启的，启动文件夹里的「大肥鱼-打完游戏恢复」开机自己恢复，开机也没恢复成，左边会黄着提示，点「恢复语音和记忆」（细节在 `记忆.md`「对电脑的影响、打游戏」）。
3. **功能和补装**：语音、记忆、表情包、看视频各一个「补装」（背后是 `import-pack.ps1 -Only <块> -Background`，页面读 `logs\import-<块>.log` 显示进度、还要几分钟和最后的 RESULT）；后台里更细的设置链接（人格、群聊插话、主动聊天、QQ 空间、看视频设置、模型和语音）；最下面是装机清单（装了什么、哪项没好、密钥和密码在哪个文件；装之前在 `logs\install-balance.json` 记过余额的，还显示这次装花了多少钱）。后台网址是 `/#/` 开头的（AstrBot 4.29.3），`/#/extension?open_config=插件名` 一打开就弹出那个插件的设置；10-28 在测试机上逐个打开核过。浏览器第一次会先要登录后台，登完回工作台再点一次。
4. **更新**：AstrBot（阿里云 PyPI）、SnowLuma（GitHub）有新版就提醒，按钮只复制一句话交给 Agent，工作台自己不升级。
5. **交给 Agent**：换角色、换声音、进群、她不回话了、搬到云上、QQ 升级后先换 NapCat、用备份还原、卸载，各一句可以复制的话，粘回 DeepSeek Harness 就会再用本 Skill。还原和卸载只在这里，不做成按钮：照 `restore.ps1`、`uninstall.ps1` 的说明先列清单，他确认了再动。
6. **帮助**：跟她聊、掉线、花钱、开机、换电脑、关了窗口会怎样，版本号。

他发来「卡在：…；原因：…；代码 …」那一句，或者桌面上的「大肥鱼求助信息-<时间>.txt」，就是工作台「复制求助信息」（`diag.ps1`）生成的：号码只留头尾，key、口令、密码都去掉了。代码对照：`BRAIN-OFF`/`BRAIN-STUCK` 大脑没开或卡住；`QQ-NOPROC` 协议端没在跑；`QQ-UPGRADE` 桌面 QQ 自动升级了、SnowLuma 挂不上；`QQ-OFF` 小号掉线；`DS-NOKEY`/`DS-BADKEY`/`DS-NOMONEY`/`DS-LOW` DeepSeek 没 key、key 不对、没钱、快没钱；`VOICE-OFF` Breeze 没开；`MEM-OFF`/`MEM-NOMODEL` Ollama 没开、bge-m3 不在；`MEM-NOKEY` 记忆接的是在线服务但没填 key；`MEM-NOPROVIDER` 记忆插件没指向记忆模型或没装上；`VIDEO-NOFFMPEG`；`VIDEO-NOASR` 视频里的话听不到（识别模型没装好）；`MEME-NET`/`MEME-MISS` 表情包下不动、没装上；`IMPORT-<块>-FAIL` 某块补装失败；`AUTO-MISS`/`AUTO-BOTH` 开机自启缺了（启动器装的大脑没开启动器的「开机自启动」也算）、设重了；`LOG-ERR` 大脑日志里有错；`OK` 都正常。

**验收**：打开后左边写「她好着呢」、她是笑着的那张图、八项都是绿的；不是绿的点那项的修复，修好了页面自己变回绿的。启动器装的 AstrBot 工作台照样能看（端口从 `private\backend.txt` 的 url 里读），只是「重启大脑」会提示去启动器里点。

## 8.4 装在云服务器上的：云端大肥鱼工作台

同一个工作台，自己认出云端模式：`<工作目录>\private\cloud.txt` 写着服务器（`host:`），这台电脑上又没有 AstrBot（没有 `start-astrbot.cmd`、`astrbot\data`）。`finish.ps1` 认出来以后只做工作台这一件：
- 这台电脑上没有 AstrBot 自带的 Python，就下一份官方便携版 Python 3.12（11 MB，国内镜像优先，校验 SHA256）解压到 `<工作目录>\python`，不装进系统、不改环境变量；
- 拷 `workbench\`、写 `tools\workbench.cmd`，桌面放「云端大肥鱼工作台」（跟本机那套的「大肥鱼工作台」不重名，同一台电脑两套都在也不打架，端口默认 26186）；
- 以前收尾放在桌面的「云端大肥鱼-打开后台.cmd」「云端大肥鱼掉线-扫码.cmd」「云端大肥鱼-说明.txt」挪进 `<工作目录>\旧版\桌面旧入口\`（不删）；
- 放「云端大肥鱼-掉线提醒」，同样在这台电脑后台盯服务器，见 8.2。

怎么看服务器：工作台每次用 Windows 自带的 `ssh`（`private\cloud_key`，`BatchMode`）连上去，把 `workbench\cloud_remote.py` 从标准输入喂给服务器上的 `python3`（不是 root 就 `sudo -n`），服务器上不留文件；页面开着时大约 8 秒问一次。另开一条隧道：本机 16185 → 服务器 6185（AstrBot 后台）、16099 → 6099（NapCat 后台），工作台退出时关掉；以前那两个 .cmd 开的隧道还在的话直接用。`cloud.txt` 认这几行：`host`（必须）、`user`（默认 root）、`port`（默认 22）、`key`（默认 `cloud_key`）、`dir`（默认 `/opt/dafeiyu`）、`expire`（到期日，`2027-10-28` 这样写，工作台里也能填）。

页面跟本机那套一样，内容换成云上的十项：**云服务器**（连不连得上、内存和硬盘还剩多少、开机多久、Docker 在不在跑）、大脑、登 QQ 的程序（NapCat，看服务器上大脑的 6199 有没有连接）、DeepSeek 余额（在服务器上用那边的 key 查）、记忆、语音、看图看视频、**服务器重启后**（Docker 开机自启、两个容器自动重启、NapCat 记没记住小号）、表情包、**到期续费**（还剩 15 天变黄）。一键操作：重启大脑、**扫码登录**（服务器上的 NapCat 停着就先开起来，二维码直接显示在工作台的弹窗里，两分钟换一张，跟着换；手机扫完点登录就好）、重启 NapCat、看日志（`docker logs`，打过码）、复制求助信息、备份到桌面（把服务器上的 `private`、`napcat/config`、`data`〔默认不带表情包〕、`compose.yml`、`.env` 拉回来打成「云端大肥鱼备份-<时间>.zip」）、AstrBot 后台、NapCat 后台（口令自动带上）、聊天记录、云控制台。补装在服务器上跑（`docker compose run --rm tools … --only <块>`，日志在服务器 `logs/import-<块>.log`）。没有打游戏模式和桌宠。

「服务器重启后」那项的「补上」：扫码登上过一次以后，把小号写进服务器 `.env` 的 `NAPCAT_ACCOUNT`，`compose.yml` 的 napcat 那段没有 `- ACCOUNT=${NAPCAT_ACCOUNT:-}` 就加上（旧文件先存进 `old/`，`docker compose config` 不过就改回去），NapCat 开着的话重建一下它，以后用快速登录、一般不用再扫码（10-29 只测了改文件，真扫码以后的快速登录没测）。

「一键更新」在云端会多做一步：新版 Skill 除了换这台电脑上的，还整包传到服务器换掉 `<dir>/kit/dafeiyu-install`（旧的挪进 `<dir>/old/kit-<版本>-<时间>`），补装用的导入工具跟着换新。版本取这台电脑和服务器上两份里旧的那个，服务器那份落后了「更新」也会亮。

云端的求助代码：`SERVER-DOWN` 连不上服务器（关机、到期停机、网络不通）；`SERVER-AUTH` 钥匙不对、权限太松或被删；`SERVER-HOSTKEY` 服务器指纹变了（重装过系统？），确认是同一台再删 `private\cloud_known_hosts`；`SERVER-SUDO` 不是 root 又不能免密 sudo；`DOCKER-OFF` Docker 没在跑；`DISK-LOW`/`RAM-LOW` 硬盘、内存快满；`NAPCAT-OFF` NapCat 停着；`QQ-QR` 在等扫码；`QQ-RISK` 手机 QQ 提示账号有风险；`QUICKLOGIN-MISS`/`AUTO-MISS` 服务器重启后要重新扫码、不会自己起来；`RENEW-SOON`/`RENEW-PAST` 快到期、过期了；其余（`BRAIN-*`、`DS-*`、`MEM-*`、`MEME-MISS`）同上。

**验收**：双击桌面「云端大肥鱼工作台」能打开，左上角写着「云服务器 · <哪家哪个城市>」，云服务器、大脑、DeepSeek 是绿的，小号登上以后登 QQ 的程序也是绿的。
