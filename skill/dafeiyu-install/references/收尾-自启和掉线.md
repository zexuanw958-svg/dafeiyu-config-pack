# 第 8 步：开机自启、掉线自救、桌面说明

家用电脑用「启动文件夹」放快捷方式就够了（他登录 Windows 时启动）。云服务器那种要断开远程也不停的，才用 S4U 计划任务（之前帮人装到云服务器的一单），这里不用。

## 8.1 开机自启和掉线自救（一个脚本）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\finish.ps1" -Dir <工作目录>
```

它做的事：
1. 启动文件夹里放快捷方式（窗口最小化）：`大肥鱼-AstrBot`（`start-astrbot.cmd`）；协议端只放现在用的那一个（看 `private\protocol.txt`，两个 connect 脚本连上时写的）：`大肥鱼-NapCat`（`start-napcat.cmd`，带小号就是快速登录，一般不用扫码）或 `大肥鱼-SnowLuma`（`start-snowluma.cmd`，另一个的快捷方式会删掉，两个都开会抢同一个小号）；选了本机记忆的放 `Ollama`（它的安装包不会自己加，坑 8）。Breeze 的安装脚本问过「开机自动启动吗」，答了要就已经有，脚本只核一下。
2. 把 `relogin-qq.ps1` 拷进 `<工作目录>\tools\`（他以后删了 Skill 也能用），桌面放「大肥鱼掉线-双击扫码」（SnowLuma 的叫「大肥鱼掉线-双击重登」，做法见 `协议端-SnowLuma.md`「开机自启和掉线」）。NapCat 的双击后：6199 有连接就说「在线，不用扫码」；AstrBot 没开先开；再不行只结束 NapCat 文件夹里的程序（他的桌面 QQ 不动），重启 NapCat 试快速登录，约 20 秒；还不行打开 `扫码登录.html` 等他扫，最多 10 分钟，二维码卡住会自己重启 NapCat。

**成功**：脚本列出放了哪几个开机自启，最后是「桌面放了『大肥鱼掉线-双击扫码』」。脚本提示「start-napcat.cmd 还没带小号」的，回协议端那份把 `connect-napcat.ps1` 跑完。
**失败先查**：桌面不一定在 `C:\Users\<名>\Desktop`（有人的是 `D:\桌面`），脚本用系统记的桌面位置；启动器装的 AstrBot 没有 `start-astrbot.cmd`，在启动器设置里开「开机自启 + 恢复运行状态 + 自启时最小化」。选 SnowLuma 的，桌面 QQ 的开机自启和自动登录要他自己在 QQ 里点（见 SnowLuma 那份）。

想让他放心，可以问他要不要现在重启电脑试一次；不想重启就算了，说清楚「下次开机等一两分钟她就在线」。

还有一种「假在线」（之前一单云服务器第二次掉线就是这样）：NapCat 和网页都显示在线，但一条消息也收不到，重启后快速登录报「登录态已失效」。判断办法是看 NapCat 日志里最后一条「接收 <-」是几点。掉线工具现在不查这个，他说「在线但不回」时你手动看。

**验收**：NapCat 的让他关掉 NapCat 窗口，双击桌面工具，能自己登回来或弹出二维码；SnowLuma 的让他在桌面 QQ 里退出小号，双击「大肥鱼掉线-双击重登」，在 QQ 窗口里点登录。

## 8.3 工作台（代替以前的《大肥鱼怎么用.txt》）

`finish.ps1` 第 3 节做这几件事：把 `scripts\workbench\` 拷进 `<工作目录>\tools\workbench\`；把 `workbench.ps1`、`common.ps1`、`backup.ps1`、`diag.ps1`、`import-pack.ps1` 拷进 `<工作目录>\tools\`（观众删了 Skill，工作台照样能修、能补装、能备份）；写 `tools\workbench.cmd`；在桌面放「大肥鱼工作台」（鲸鱼图标）；再生成一份兜底静态页。打开给他看，让他自己双击桌面「大肥鱼工作台」，或者你在他桌面会话里跑：

```powershell
& "<工作目录>\tools\workbench.cmd"
```

双击以后：`workbench\open.ps1` 找 AstrBot 自带的 Python（命令行装的在 `<工作目录>\uv\tools\astrbot\Scripts\`，启动器装的在实例的 `venv\Scripts\`），用 `pythonw.exe` 起一个本机小服务（`server.py`，只听 127.0.0.1，端口默认 26185，被占就随机），再用 Edge 开一个没有地址栏的小窗口（1100×760 左右，Edge 已经开着时页面自己调大小）。服务已经在跑就只开窗口。窗口关了 3 分钟、又没有在跑的长动作，服务自己退出。找不到 Python 时退回 `workbench.ps1` 的静态页（只能看、不能修）。

页面左边是鱼缸：大肥鱼的表情和台词跟着状态变，下面一张卡写着现在最要紧的一件事和一个修复按钮。右边六页，按 `answers.json` 里他装了什么自动增减：
1. **她的状态**：今天收到几条消息、她回了几次、吃掉多少 token、记住几件事（都从 AstrBot 本机数据库里只读出来，拿不到的格子不显示）；八项检查（大脑、登 QQ 的程序、DeepSeek 余额、记忆、语音、看图看视频、开机自启、表情包），出问题的那项带「一键修复」。
2. **一键操作**：重新登 QQ（弹出 `tools\relogin.cmd` 那个窗口）、重启大脑、重启登 QQ 的程序（只停工作目录里的，不碰桌面 QQ）、复制求助信息、备份到桌面、看最近日志（打过码），还有直达 AstrBot 后台、协议端后台、聊天记录。选了本机语音或本机记忆的，第一个是**打游戏模式**：关掉 Breeze 和 Ollama 腾出显卡和内存，她只打字照常聊，打完点「打完了，恢复」；没恢复就重启的，启动文件夹里的「大肥鱼-打完游戏恢复」开机自己恢复，开机也没恢复成，鱼缸会黄着提示，点「恢复语音和记忆」（细节在 `记忆.md`「对电脑的影响、打游戏」）。
3. **功能和补装**：装机清单（装了什么、哪项没好、密钥和密码在哪个文件；装之前在 `logs\install-balance.json` 记过余额的，还显示这次装花了多少钱）；语音、记忆、表情包、看视频各一个「补装」（背后是 `import-pack.ps1 -Only <块> -Background`，页面读 `logs\import-<块>.log` 显示进度、还要几分钟和最后的 RESULT）；后台里更细的设置链接（人格、群聊插话、主动聊天、QQ 空间、看视频设置、模型和语音）。后台网址是 `/#/` 开头的（AstrBot 4.29.3），`/#/extension?open_config=插件名` 一打开就弹出那个插件的设置；10-28 在测试机上逐个打开核过。浏览器第一次会先要登录后台，登完回工作台再点一次。
4. **更新**：AstrBot（阿里云 PyPI）、SnowLuma（GitHub）有新版就提醒，按钮只复制一句话交给 Agent，工作台自己不升级。
5. **交给 Agent**：换角色、换声音、进群、她不回话了、搬到云上、QQ 升级后先换 NapCat、用备份还原、卸载，各一句可以复制的话，粘回 DeepSeek Harness 就会再用本 Skill。还原和卸载只在这里，不做成按钮：照 `restore.ps1`、`uninstall.ps1` 的说明先列清单，他确认了再动。
6. **帮助**：跟她聊、掉线、花钱、开机、换电脑、关了窗口会怎样，版本号。

他发来「卡在：…；原因：…；代码 …」那一句，或者桌面上的「大肥鱼求助信息-<时间>.txt」，就是工作台「复制求助信息」（`diag.ps1`）生成的：号码只留头尾，key、口令、密码都去掉了。代码对照：`BRAIN-OFF`/`BRAIN-STUCK` 大脑没开或卡住；`QQ-NOPROC` 协议端没在跑；`QQ-UPGRADE` 桌面 QQ 自动升级了、SnowLuma 挂不上；`QQ-OFF` 小号掉线；`DS-NOKEY`/`DS-BADKEY`/`DS-NOMONEY`/`DS-LOW` DeepSeek 没 key、key 不对、没钱、快没钱；`VOICE-OFF` Breeze 没开；`MEM-OFF`/`MEM-NOMODEL` Ollama 没开、bge-m3 不在；`VIDEO-NOFFMPEG`；`MEME-NET`/`MEME-MISS` 表情包下不动、没装上；`IMPORT-<块>-FAIL` 某块补装失败；`AUTO-MISS`/`AUTO-BOTH` 开机自启缺了、设重了；`LOG-ERR` 大脑日志里有错；`OK` 都正常。

**验收**：打开后鱼缸写「她好着呢」、八项都是绿的；不是绿的点那项的修复，修好了页面自己变回绿的。启动器装的 AstrBot 工作台照样能看（端口从 `private\backend.txt` 的 url 里读），只是「重启大脑」会提示去启动器里点。
