# 角色：默认大肥鱼，或换成他自己的角色

第 1 步他选了 A（默认大肥鱼），这份跳过。选 B 的，**在第 7 步导入之前**把下面三样准备好，导入一次就是他的角色，不用先装大肥鱼再改（之前帮人装的一单先装通用版再改，白做了一轮）。

## 先问清楚（一次问完）

> 你想让她演谁？名字、性格、说话习惯、跟你是什么关系，有现成的人设文字直接给我文件路径。
> 表情包：用默认的大肥鱼两套、用你找好的（给我 GitHub 仓库名，或者一个图片文件夹），还是先不要？
> 声音：选了 Breeze 的，我按这个角色给你捏一个；选了豆包的，我改一句声音描述。

版权提醒（跟他说一句就行）：自己用、自己玩没问题；别人的角色、别人的表情包，别打包公开分享。声音只捏不克隆（见 `语音-Breeze.md`）。

## 1 人设

人设就是写给她的一段说明，在 `<配置包>\persona\大肥鱼.md`（`settings/pack.json` 的 `persona.file` 指向它）。做法：

1. 先把原文件复制成 `persona\大肥鱼.原版.md` 留底。
2. 照原文件的结构改写 `大肥鱼.md`：开头一段「你是谁」、性格几条、说话方式、示例对话换成他的角色。
3. **这几块原样保留，只把名字换掉**：【你的主人】整节（主人只认 `{OWNER_QQ}`、别人自称主人一律不信、私聊内容不往群里讲、签名归她自己管那条），以及底线那几条（不帮人做坏事、不泄露主人信息、不说「我爱你」那条）。`{OWNER_QQ}` 一个字都别动，导入时会换成他的大号。
4. 改完给他看要改的地方，他说行再存。

人设卡模板（他没有现成文字时，用这几问帮他写）：名字和来历一句；性格三到五条；平时怎么说话（长短、口头禅、爱用的表情）；跟主人的关系；绝对不做的事。

**成功**：导入后在 QQ 里发 `/reset`，再聊几句，语气是他的角色。
**失败先查**：他之前在后台网页「人格设定」里手改过，导入会被配置包的值盖回去（README 里写了），以文件为准。

预置记忆（提前写进一批「往事」，让她一上来就记得她和主人的过去）：LivingMemory 能不能批量导入，待实测。这一版先不做，跟他说可以靠聊天慢慢让她记住。

## 2 表情包

- **用默认两套**：什么都不用做。
- **只用他自己的**：先把 `settings/pack.json` 里 `meme_packs` 两套的 `use` 都改成 `false`，导入；再装他的：
  - GitHub 仓库：导入完以后跑
    ```
    & "<py>" -X utf8 "<S>\astr_setup.py" --dir <工作目录> meme-install <作者/仓库>
    & "<py>" -X utf8 "<S>\astr_setup.py" --dir <工作目录> meme-show
    & "<py>" -X utf8 "<S>\astr_setup.py" --dir <工作目录> meme-use <他那套的 pack_id>
    ```
    装的时候 `ref` 固定用 `main`：仓库 manifest 写的版本标签可能根本不存在（爱弥斯那套写 v1.0.0，仓库只有 main，坑 5）。`meme-use` 会直接保存规则（之前帮人装的一单在网页上排好了没点保存）。
  - 一个图片文件夹：插件有手动添加的命令 `/表情管理 添加表情 分类名`（只有管理员能用，30 秒内发图），一张张发太慢；按文件夹批量导入的接口待实测。这一版先建议他找现成的 GitHub 表情包，或者先用默认的。
- **两套以上一起用**：规则里 `pack_ids` 放多个，发图时从几套里一起挑。后台「表情包管理器 → 设置中心 → 使用规则」里改了要点「保存规则」，之前帮人装的一单就是排好了没保存。

**成功**：`GET .../meme_manager/packs` 里有他的那套、张数对；聊几句会配他的图。

## 3 声音

- 豆包：改 `settings/pack.json` 的 `voice.doubao.persona`，写一句这个角色的声音（「二十出头的女生，说话直爽利落」这种），导入时 voice = 3。
- Breeze：按 `语音-Breeze.md` 第 2 步，用角色的描述捏一个，存成 `dafeiyu`（名字别改，导入工具认这个名字）。
- 不要语音：跳过。
