# 备份、换电脑和卸载

他说「备份一下」「换电脑了」「重装系统前」「不想要了」「卸干净」时读这页。三个脚本都在 `<S>`（Skill 的 scripts 文件夹）里，都只认工作目录（体检报告「工作目录」那行，或 `%LOCALAPPDATA%\dafeiyu\workdir.txt`）。

## 备份

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\backup.ps1" -Dir <工作目录>
```

- 打成桌面上的 `大肥鱼备份-<日期时间>.zip`：`private\`（key、后台密码、QQ 号）和 `astrbot\data`（人格、记忆、聊天记录、插件设置）。表情包默认不带（几百 MB，重装时会重新下）；他自己往里加过表情、想一起留着，加 `-WithMemes`。
- AstrBot 开着也能备份。
- 跑完跟他说：**包里有他的密钥，只给自己留着，别发给任何人，别传网盘分享。** 桌面所在的盘不够放，加 `-Out D:\大肥鱼备份.zip` 换个盘。
- 工作台上也有「备份」按钮，背后是同一个脚本。

## 换电脑、重装以后还原

1. 新电脑上照 Skill 从头装到第 6 步「能聊」（主路通了就行，可选功能先别装）。
2. 把备份 zip 拷过来，跑：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\restore.ps1" -Dir <工作目录> -Zip <备份 zip 的路径>
   ```

   它会停 AstrBot、把现在的 `private`、`astrbot\data` 改名成「.还原前-<时间>」留着、放回备份、再开 AstrBot。后台密码变回备份里那个。备份里没带表情包的，用这次新装好的那几套。
3. 登 QQ 的程序（NapCat、SnowLuma）不在备份里：照第 4、5 步重新登小号。
4. 它最后要是说「备份是从 X 打的，现在的工作目录是 Y」，并且他开着看视频，跑 `import-pack.ps1 -Only video` 把插件里的路径改过来。
5. 验收：让他问一件以前跟她聊过的事，看她还记不记得。

还原坏了：把两个「.还原前」文件夹改回原名（先停 AstrBot），就回到还原前的样子。

## 卸载

**先列清单，他确认了才删。**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\uninstall.ps1" -Dir <工作目录>
```

不加 `-Yes` 只列清单、什么都不删。把清单原样转给他：工作目录里要删哪几样、各多大，桌面和开机自启里哪几个快捷方式，后台计划任务，环境变量。工作目录里他自己放的文件会单独列出来，说明「留着不动」。

问他两件事：要不要先留个备份（以后想回来，装好主路就能还原人格和记忆）；Ollama 装在默认位置的（清单里会写），我们下的 bge-m3 模型（约 1.1 GB）要不要一起删。他回「确认」后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\uninstall.ps1" -Dir <工作目录> -Yes [-Backup] [-RemoveOllamaModel]
```

- 删掉的东西进回收站，他想腾空间就清空回收站。
- 只删我们装的：工作目录里各安装脚本建的那些文件夹和文件、指向工作目录的快捷方式和 `dafeiyu-*` 计划任务、指向工作目录的 `OLLAMA_MODELS`。装在工作目录里的 Ollama 用它自己的卸载程序卸。桌面 QQ、AI 帮手本身不动。
- 退出码 2：有东西被占着没删掉。SnowLuma 那条路要他先退出桌面 QQ（右下角企鹅图标右键 → 退出），再重跑同一条命令；别的重启电脑后重跑。
- 退出码 3：要了备份但没备份成功，什么都没删。

删完转告他两件事（脚本最后也会打出来）：
1. 去 DeepSeek 开放平台「API keys」把这个 key 删掉；豆包、硅基流动的也一样。
2. 手机 QQ 登小号 → 设置 → 账号安全 → 登录设备管理，把这台电脑移除。

ceshi 上用假的安装目录测过（10-28）：只剩他自己的文件；名字很像但指向别的目录的快捷方式、计划任务没被碰；还原后旧文件夹留着、表情包从新装的挪过来。Ollama 自带卸载程序那段没真跑过（测试机的 Ollama 不在工作目录里）。
