# 第 6、7 步：导入大肥鱼配置包（先变成大肥鱼，再一块一块加）

实测：10-25 P2（DSH 跑通，2 分 13 秒，约 8 分钱，15 项全勾）、P3、P4；10-27 选 4（Breeze）全绿。10-28 导入工具拆成几块以后，在 ceshi 上 `--only core` 3 秒、全装 16 项全勾；表情包删掉一套再装回来（143 MB），后台下载、每 10 秒报一次进度，装完自动设成两套一起用。

## 为什么分块

上一期很多人卡在「表情包下不动，后面全停」：旧的导入工具一口气装插件、表情包、记忆、语音，最后才把她设成默认人格；表情包 630 MB 从 GitHub 下，网慢就超时，工具整个崩掉，她还是 AstrBot 默认的助手。现在：

| 块 | 做什么 | 要下载吗 | 失败了会怎样 |
|---|---|---|---|
| `core` | 关深度思考、写人格、**设成默认人格**、分段回复、白名单、认主人 | 不下载，几秒 | 只有后台登不上、读不到配置才会失败 |
| `plugins` | 插件市场的 6 个插件 + 配置包自带的插件（去标签、改签名；选豆包的加豆包语音插件），改插件设置 | 插件市场是 AstrBot 自己的服务器（国内能连），几 MB 一个 | 少哪个就少哪个功能，照常聊天 |
| `video` | 看视频插件（回答文件里 `video` 是 `"1"` 才装） | 插件在配置包里，不下载；ffmpeg 和识别模型由 `install-ffmpeg.ps1`、`install-asr.ps1` 先下好 | 没 ffmpeg 她会说看不了视频；没识别模型就只看画面 |
| `memory` | 记忆模型接到记忆插件，测通了才打开；记忆范围设成「他的 QQ 私聊和桌宠共用一份、每个群各记各的、没登记的群不记」（`记忆.md`「记的范围」） | 本机记忆不在这里下：`install-ollama.ps1` 先把 bge-m3 下好 | 记忆先关着，照常聊天 |
| `voice` | 语音提供商，试念一句，通了才打开 | 豆包、Breeze 都不在这里下大文件 | 语音先关着，照常聊天 |
| `memes` | 两套表情包（小的 143 MB 先装，大的 485 MB 后装），设成一起用 | 从 GitHub 下，经加速地址；最大、最容易卡，永远最后、放后台 | 先不配图或少一套，照常聊天 |
| `pet` | 电脑桌宠也是她：桌宠互通插件 + 记忆范围（只由 `setup-pet.ps1` 调，见 `桌宠.md`；不点名不装） | 不下载 | 桌宠照旧是 dsh-pet 自己的人设，QQ 里的她不受影响 |

每块单独跑、单独报结果。一块里出了任何错（包括超时、后台断开），工具只记一个叉、接着跑下一块，最后的结果清单一定会打出来。

每块最后一行是给你读的：

```
RESULT memes=partial reason=network:blue-fat-fish-meme-pack next=过一阵补装：--only memes（她照常聊天，只是先不配图或少一套）
```

`ok` 成了；`partial` 成了一部分；`fail` 没成；`skip` 他没选这项或者缺前提。照 `next` 跟他说怎么补，别自己去翻报错。

## 7.1 拿到配置包

- Skill 文件夹里带着一份（`<S>\..\pack\dafeiyu-config-pack`，发布时打进去的，见本文末）：**不用你动手**，`import-pack.ps1` 发现工作目录里没有配置包、或者是不认 `--only` 的旧包，会自己把这份拷过去（旧包改名成「.旧-<时间>」留着），不用联网。下面两条只在 Skill 里没带 `pack` 文件夹时才用。
- 没带的：他已经从飞书教程下过 zip 的，解压到 `<工作目录>\dafeiyu-config-pack`。
- 都没有：从 GitHub `zexuanw958-svg/dafeiyu-config-pack` 下 zip（`https://github.com/zexuanw958-svg/dafeiyu-config-pack/archive/refs/heads/main.zip`，先加载 `. "<S>\common.ps1"`，再用 `Get-GitHubFile -Url <地址> -OutFile <zip路径> -MinBytes 100000` 走加速列表），解压后把 `dafeiyu-config-pack-main` 改名成 `dafeiyu-config-pack`。小 zip 的 `-MinBytes` 保持 `100000`，别填 1 MB，否则可能把完整的小包当成失败。下载超过 15 秒会报进度，中断重跑会续传，地址不支持续传才清掉半截重下；下好且能解压出 `tools\import_dafeiyu.py` 才算拿到了。用时看网速，优先用 Skill 自带的那份。
- 版本要够新：`tools\import_dafeiyu.py` 开头的说明里要有「分成几块」和 `--only`。旧包一律换新包。

## 7.2 写回答文件

**别双击 `导入大肥鱼.bat`**：它一问一答，最后停在「按任意键」，你会卡住。写 `<工作目录>\answers.json`（DSH 的沙箱可能不让你往配置包文件夹里写，10-25 P2 就碰到过，写在工作目录里最省事）：

```json
{
  "base_url": "http://127.0.0.1:<后台端口>",
  "username_file": "<工作目录>\\private\\backend.txt", "username_key": "username",
  "password_file": "<工作目录>\\private\\backend.txt", "password_key": "password",
  "owner_qq_file": "<工作目录>\\private\\owner-qq.txt",
  "memory": "1",
  "voice": "3",
  "volc_app_id_file": "<工作目录>\\private\\volc.txt", "volc_app_id_key": "app id",
  "volc_access_token_file": "<工作目录>\\private\\volc.txt", "volc_access_token_key": "access token"
}
```

- `memory`：1 本机 Ollama、2 硅基流动（加 `siliconflow_key_file`）、0 不要（会把记忆插件关掉，记住的不删）。别不写：没写的话导入工具不动记忆（`RESULT memory=skip reason=not-in-answers`），以前的版本会默认当成 2。
- `voice`：3 豆包（要 volc 那两项）、4 Breeze（不要 key，先装好并做好 `dafeiyu` 声音）、1 Edge 免费女声（不要 key、不用实名，未满 18 岁办不了豆包的可以用它；10-28 在没走代理的阿里云北京服务器上实测能合成，一句 2–3 秒；要 ffmpeg，先跑 `install-ffmpeg.ps1`）、0 不要。2 小米 MiMo 克隆（要 `mimo_key_file`）不在第 1 步的选项里，他主动要再用。
- `video`：填 `"1"` 装「大肥鱼看视频」插件，同时加 `"ffmpeg_path"`（`install-ffmpeg.ps1` 打出来的路径）和 `"asr_dir"`（`install-asr.ps1` 打出来的文件夹），见 `看图看视频.md`。不填就不装。看图不用填，`core` 自动打开。
- `sing`：唱歌插件默认不装、不对外承诺；只有他点名要、并且 `voice` 是 3（豆包）时才填 `"1"`。
- `meme_zip_dir`（可选）：表情包 zip 已经下好放在某个文件夹里（文件名 `<表情包id>.zip`），填这个文件夹，`memes` 就从本地导入、不连 GitHub。
- `meme_copy_from`（可选）：本机另有一套装过表情包的（「另装一套」时），填那套的 `<旧工作目录>\astrbot\data\plugin_data\meme_manager`，`memes` 就把那边装好的直接导进来、不重下（走插件自己的导入接口，不用停 AstrBot）。**别自己拷文件夹再重启**：10-28 桌面版 DSH 这么干，插件重启后不认，又从头下了 460 MB。
- 只写路径，不写秘密。`*_key` 填文件里冒号前的名字，小写。
- 回答文件一直留着、一直填他现在的选择。用 `--only` 跑时，没点名的块根本不碰，所以不会再出现「重跑时填 0 把已经开着的记忆或语音关掉」。

## 7.3 运行：一块一块来

都用 `import-pack.ps1`（它自己找 AstrBot 的 Python、配置包和回答文件）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\import-pack.ps1" -Dir <工作目录> -Only <块>
```

顺序（他在第 1 步 B 里选了「只拿几样」的，不照这个顺序，看 7.5）：

1. **第 6 步「能聊」一通过，马上跑 `-Only core`**（几秒）。看到 `RESULT core=ok`，跑 `astr_setup.py --dir <工作目录> greet`：她会主动给大号发一句招呼（大肥鱼口气，随机一句；他换了自己的角色，你按那个角色写一句，`greet 「……」`；想先给他看要发哪句，加 `--dry` 只说不发。QQ 平台不叫「大肥鱼」的（装过上一期来补装的）会自动挑 QQ 那个平台）。叫他看手机 QQ，先回 `/reset`（清掉刚才默认助手的对话），再随便聊一句。语气是大肥鱼了，**主路就算完成**。`greet` 报「没发出去」不要紧，让他自己发「在吗」就行，跟他说一声「她已经是大肥鱼了，接下来一项一项加功能，哪项下不动都不耽误她聊天」。
2. `-Only plugins`（第一次一两分钟）。
3. 选了看视频：先 `install-ffmpeg.ps1`、`install-asr.ps1`（5C 加 `-Plus`），再 `-Only video`。
4. 选了记忆：本机的先 `install-ollama.ps1`（它把 bge-m3 下好），再 `-Only memory`；在线的直接 `-Only memory`。
5. 选了语音：Breeze 先照 `语音-Breeze.md` 装好、做好声音，豆包先照 `语音-豆包.md` 拿到两项凭证，再 `-Only voice`。
6. 表情包放最后、放后台：`-Only memes -Background`。脚本马上返回，日志在 `<工作目录>\logs\import-memes.log`。你每半分钟读一次最后几行（`Get-Content -Encoding UTF8 -Tail 6 <日志>`），转述「表情包已下 80 MB」这样的进度；他可以一边等一边跟她聊。出现 `RESULT memes=` 那一行就是跑完了。

每块开始前跟他说要下多大、大概多久；跑完照 `RESULT` 那行转述。可能会弹你自己的权限确认（要跑 AstrBot 目录里的程序），叫他点允许。

**快照和退回**：每次跑之前导入工具先把现在的设置存一份（全局设置、人格列表、配置包那几个插件的设置和开关、表情包规则、工具权限；不存聊天记录和表情包图片），在 `<工作目录>\private\snapshots\before-<块>-<时间>.json`，第一次那份另存 `original.json`，最多留 20 份。输出里 `SNAPSHOT <路径>` 那行就是这次的。改之前只想存一份：`import-pack.ps1 -Dir <工作目录> -Snapshot`。退回：`import-pack.ps1 -Dir <工作目录> -Restore`（回到 `original.json`），或加 `-From <快照文件>` 退到那一份；成功是最后一行 `RESULT restore=ok`。退回只改回设置、不删东西：之后新建的人格留在列表里，配置包新装的插件关掉、不卸载，导入时新建的记忆、语音模型关掉。改回后让他在 QQ 里发 `/reset` 再聊。后台密码不跟着退（快照里不存）。

想一次全装（比如他重装、你确定网好），`-Only core,plugins,video,memory,voice,memes` 也行，但表情包那块还是单独放后台更稳。

**失败先查**（看打叉那一行自带的提示和 `RESULT` 的 `reason`）：
- `core=fail reason=login`：`backend.txt` 过期了（他在网页上改过密码），让他把新密码写回去（坑 6）。
- `plugins=fail reason=market:…`：插件市场的服务器一时没响应。过几分钟重跑 `-Only plugins`，装好的会跳过。
- `memes=fail` 或 `partial`，`reason=network:…`：几个 GitHub 加速地址都没下动（工具会每套从头试一遍：两分钟没进展就取消、换下一个；试的时候会临时改表情包插件的「GitHub 加速地址」，最后都没成就改回原来的，不会把他留在直连 GitHub 上）。跟他说「表情包这会儿下不动，先跳过，不影响聊天；过一阵我再补，或者你在工作台点『补装表情包』」，过一阵重跑 `-Only memes -Background`。
- `memes` 日志里「后台还有一套表情包在装」：上次的下载还在跑，工具会等它结束（最多 20 分钟）。
- `memory=fail reason=ollama`：Ollama 没开或 bge-m3 没下好，先回 `记忆.md`。
- `memory=fail reason=no-key`：选了硅基流动，但 key 文件是空的，后台里也没有现成的硅基流动 key。记忆插件关着（不建空 key 的模型）。让他把 key 粘进 `siliconflow_key_file` 指的文件、保存，再 `-Only memory`；不想要在线的就改 1 或 0 再跑。
- `memory=fail reason=test`：key 试了没通（粘错、没实名、欠费），记忆插件关着，照 `记忆.md` B 段查。
- 记忆块输出里有 `MIGRATE private-memories`：他以前就装着记忆插件，私聊里记住的事还在旧位置，替他搬一次（`桌宠.md`「旧记忆搬家」）。
- `video=partial reason=no-asr`：看视频插件装好了，但本机识别没装好、也没有硅基流动 key，她只看画面。照 `看图看视频.md`「本机识别下不动」给他挑。
- `voice=fail`：豆包报 45000030 见 `语音-豆包.md`；Breeze 连不上或没有 `dafeiyu` 见 `语音-Breeze.md`。
- 某块 `reason=error:…`：这块里出了没料到的错，工具已经跳过它、接着装别的。把那块前面几行日志看一下，修好重跑 `-Only <块>`。

## 7.4 导完顺手核一下

- 群里会不会配表情包：meme_manager 配置 `generation.trigger.scope` 应该是 `chat_and_plugin_llm`（`plugins` 块会自动设；是 `only_chat_llm` 的话群里一张不发，改掉）。
- 群聊插话概率 `astrbot_plugin_group_chat_plus` 的 `initial_probability`：默认 0.02，不要调到 0.1 以上（之前一单云服务器 26 分钟发了 43 条，两小时被踢两次）。
- 看图：群聊插件 `enable_image_processing` 是 true、`image_to_text_scope` 是 `mention_only`（`plugins` 块自动设）。
- 「操作电脑」还是关的：`provider_settings.computer_use_runtime` = `none`。导入工具不会打开它，但核一下。

## 7.5 只拿几样（他自己配的机器人，人设不动）

第 1 步 B 里他选了「只拿几样」。他的人设、聊天设置（拆几条发、记多少轮、白名单、管理员这些）都不动，只装他在问 ③「只拿几样」版里挑的块。

**准备**
- 工作目录照问 ② 建，`private\backend.txt` 写他那套 AstrBot 的 `url`、后台账号、密码（`基础-AstrBot和DeepSeek.md`「已经用启动器装过」）。
- 配置包放 `<工作目录>\dafeiyu-config-pack`（7.1）。
- `answers.json` 照 7.2 写，**加 `"keep_persona": "1"`**；`base_url` 写他那套的后台地址；`owner_qq_file` 照写（主动聊天、改签名、发空间要认主人）。他没挑的项（`memory`、`voice`、`video`）别写。
- 他手动装的 AstrBot，`import-pack.ps1` 找不到它自带的 Python：每条命令加 `-Python <他那套的 python.exe>`。

**`keep_persona` 让导入工具怎么做**（不用你另外处理，看输出核对就行）：
- 不跑 `core`：误跑了也只出 `RESULT core=skip reason=keep-persona`，什么都不改。
- `plugins`：不装表情包插件和记忆插件（他挑了的，由 `memes`、`memory` 两块自己装）；他原来就装着的插件，设置一个字不改（输出「你原来就装着的，设置不动：…」），新装的才用配置包的设置；他原来设过权限的工具不动。
- 他原来的设置里有这几样，工具只提醒、不替他改，你照提醒转述给他：主人的 QQ 不在管理员里（发空间、改签名只听管理员的，要加就照第 5 步 `whitelist` 问他）；没设「图片转述模型」（群里没 @ 她的图不会先看一眼）；他的对话模型没开看图（看视频只能听声音）。
- 每次改之前自动存快照，输出里有 `SNAPSHOT <路径>`。

**顺序**（每块成功是 `RESULT <块>=ok`；最后核一次 `status`，「4 角色」那行还是他原来的名字）：

| 他挑的 | 跑什么 |
|---|---|
| 5A 群聊和小功能 | `-Only plugins` |
| 4 看视频 | `install-ffmpeg.ps1`、`install-asr.ps1`（4C 加 `-Plus`），再 `-Only video` |
| 3 记忆 | 本机的先 `install-ollama.ps1`，再 `-Only memory`；在线的直接 `-Only memory`（记忆插件这块自己装） |
| 2 语音 | 先按他的角色改声音描述（下一段），再 `-Only voice` |
| 1A 表情包 | 放最后、放后台：`-Only memes -Background`（表情包插件这块自己装） |

**语音的声音描述**：配置包里的是给大肥鱼写的。豆包（voice 3）：按 `角色包.md` 第 3 节，照他角色的性格写一句，改 `<工作目录>\dafeiyu-config-pack\settings\pack.json` 的 `voice.doubao.persona`，先念给他听、他点头了再跑。Breeze（voice 4）：按 `语音-Breeze.md` 第 2 步用他角色的描述捏几个，或者拿角色的录音克隆，他挑好了存成 `dafeiyu`（名字别改，导入工具认这个）。导入时工具会把用的那句描述打出来，还是「憨萌软糯的小女生」那句就是忘了改。

**表情包**：图全是大肥鱼的（蓝色小鲸鱼和 DeepSeek 二创），问的时候就说清楚。他原来就有表情包插件和自己的图的，工具把大肥鱼这两套加在他原来那几套后面一起用，不替换。

**收尾这样说**（别说「她已经是大肥鱼了」）：

> 「〔咕咕嘎嘎〕」还是原来的她，人设和聊天设置都没动。新加了：〔表情包、语音……〕。去 QQ 上跟她聊两句试试。哪样不喜欢，或者想全部退回到装之前，跟我说「退回去」就行。

## 给我们自己：Skill 里带一份配置包

发布 Skill 压缩包用 `skill-draft/打包发布.py`（Mac 上跑，`--forbid <文件>` 填测试用的号码）：它把配置包当前工作区按 `.gitignore` 挑文件（不带 `.git`）放进 `dafeiyu-install/pack/dafeiyu-config-pack/`，写 `pack/版本.txt`，打完扫一遍 key、密码行和禁止的号码，扫到就删包。配置包是 MIT 许可，可以这么带。10-28 在 ceshi 上验过：Windows 自带解压中文名正常，`import-pack.ps1` 自动用上了自带的包。
