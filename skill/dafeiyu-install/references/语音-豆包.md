# 语音 A：豆包 Seed Audio（默认，导入时 voice = 3）

最像真人；按语音时长收费，约 1 元/分钟，新账号首次领试用送 60 分钟（有效期半年）。整条回复合成一条语音，要等 15–35 秒。实测：Vol.04 正式实例、10-25 P2/P3/P4 都选的 3。

观众要的步骤全文在 Vol.04 `工作记录/豆包语音申请步骤.md`（飞书教程里也有），这里只放你要做的。

## 1 拿 APP ID 和 Access Token（停下来叫人，整段都是他本人操作）

你帮他打开网页，一步一句话带着走：

1. 注册火山引擎（手机号 + 验证码）。
2. 个人实名认证（扫脸或银行卡，18 岁以上、大陆身份证）。没实名用不了。
3. 进豆包语音控制台：控制台左上角菜单里搜「豆包语音」。确认左上角是**旧版**，不是就切（下拉框，或直接开 `https://console.volcengine.com/speech/app`）。新版发的是 API Key，我们的插件只认旧版的 APP ID + Access Token。
4. 旧版「应用管理」里有应用就用，没有就建一个。名字只能用英文、数字、下划线、中划线，4–30 个字（写中文会被拒），比如 `dafeiyu`；「应用简介」必填，随便写一句；「接入能力」至少勾一项，勾「豆包音频生成模型1.0」。提交时弹「确认后将开启免费试用版，并赠送试用额度」，点「确认」，这一下就是领试用。
5. 「API服务中心」→ 选「豆包音频生成模型1.0」→ 上面「应用名称」选这个应用，看到版本是「试用版」就对了。有的账号这里还有一个「试用」按钮，有就点它。**别点「开通」**：开通就转正式版开始扣钱，试用额度清零。
6. 同一页往下拉到「服务接口认证信息」，第一列是 APP ID，第二列是 Access Token（默认是星号，鼠标移上去点小眼睛才显示，旁边有复制图标）。应用管理列表里只有 APP ID，没有 Token。
（10-28 照这几步实录过一遍，界面以那次为准。）

然后建 `private\volc.txt`，记事本打开，让他按两行粘：

```
app id: 这里粘 APP ID
access token: 这里粘 Access Token
```

回答文件里：`"volc_app_id_file": "<工作目录>\\private\\volc.txt", "volc_app_id_key": "app id", "volc_access_token_file": 同一个文件, "volc_access_token_key": "access token"`。

**成功**：导入工具结果里语音那一项打勾，并且试合成成功。聊到她回一条语音以后，问她「你刚才那条语音说的啥」，她能说出内容，而不是「我只会打字」；说不出来，看后台插件列表里 `astrbot_plugin_dafeiyu_clean` 是不是 v0.2.0 以上。
**失败先查**：
- 报 `45000030 requested resource not granted`（观众真实卡点）：这个应用没领 Seed Audio 1.0 的试用（第 5 步没做或点错了），或者 APP ID 是别的应用的。回控制台核对。
- 新账号在服务列表里找不到「豆包音频生成模型1.0」：这个模型发布时是邀测，新账号能不能直接开，文档没写清（待实测）。找不到就建议他先选 Breeze 或「先不要」。

## 2 声音描述

豆包的声音是一句话描述出来的，在配置包 `settings/pack.json` 的 `voice.doubao.persona`。选了「换成自己的角色」的，按角色改这句（见 `角色包.md`）。

## 不提唱歌

大肥鱼 2.0 只承诺「会发语音」，不承诺唱歌（10-27 定的：唱歌效果不好）。对观众不提唱歌、不验收唱歌。

维护者注：配置包现在的导入工具在语音选 3 时会顺带装 `astrbot_plugin_dafeiyu_sing`（`plugins/` 里的额外插件，`import_dafeiyu.py` 里有「唱歌后端」）。发布 2.0 前要定：从配置包里拿掉，还是加一个开关默认不装。没改之前，这个插件会装上但 Skill 不提它。
