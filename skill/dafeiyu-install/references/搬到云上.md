# 一键搬上云：把这台电脑上的她搬到云服务器

他说「搬到云上」「电脑关机她也在线」「不想一直开着电脑」时读这页。她已经在这台电脑上养好了，走这页，不用照 `云端.md` 从头装一遍：记忆、人设、聊天记录、白名单、插件和插件设置、表情包都带着走。

全程他只做三件事：买服务器、在网页终端粘一行、用手机扫码。别的都由脚本做。

`<本机>` 是现在的工作目录，`<云端>` 是新建的云端工作目录，就用 `<本机>-cloud`（例如 `C:\dafeiyu-cloud`）。下面的 Python 用 `Find-AstrPython` 找到的那份，加 `-X utf8`。

## 1 先讲清楚

照 `云端.md`「先讲清楚利弊」那段讲，再加这三句：

> 搬的时候她要下线一会儿，传数据加上重新扫码，一般半小时内。
> 带不走的有三样：本机语音（服务器没显卡，换成 Breeze 在线版、豆包或 Edge）、这台电脑的 Ollama（记忆换成硅基流动在线，同一个模型，以前记住的都带着）、桌宠（桌宠在这台电脑上，留不住）。
> 这台电脑上的数据一个字不动，只把开机自启收起来。搬完不满意能退回来，但搬完以后云上新记住的事带不回来。

他还没买服务器的，照 `云端.md` C0 带他挑，**不替他买**。

记忆在本机 Ollama、又没有硅基流动 key 的，问他要不要现在建一把（`记忆.md` B 那节有怎么带他建），粘进 `<本机>\private\sf-key.txt`。不建也能搬，记忆文件带过去但先关着。语音要 Breeze 在线版的先照 `语音-Breeze在线.md` 第 1、2 节把 key 放进 `<本机>\private\breeze-key.txt`。

## 2 连上服务器

照 `云端.md` C1 做，所有文件放 `<云端>\private`（`cloud.txt`、`cloud_key`）。**成功**：C1 第 6 步打印 `ok`。

## 3 看一眼计划（只读）

```powershell
& <python> -X utf8 "<S>\move_to_cloud.py" --dir <本机> --cloud-dir <云端> plan
```

打出来的 `PLAN` 几行照着告诉他：带什么、带不走什么、语音和记忆换成什么、大概下线多久。最后一行 `RESULT`：

- `RESULT ok`：等他回「搬」再往下。
- `RESULT need_human …`：照那句做。服务器上已经有 `/opt/dafeiyu` 或 astrbot、napcat 容器的，先问他里面的东西还要不要：不要了加 `--replace-existing`（整个目录改名挪到旁边，不删）；要的话照 `云端.md`「服务器上已经有他自己的机器人」。

想换语音的加 `--voice 5|3|1|0`（5 Breeze 在线、3 豆包、1 Edge、0 不要），不要记忆的加 `--memory off`。

## 4 搬

他回「搬」以后再跑，放后台，不占着窗口（总共十几分钟到一小时，看他家上传多快）：

```powershell
Start-Process <python> -ArgumentList '-X','utf8','"<S>\move_to_cloud.py"','--dir','"<本机>"','--cloud-dir','"<云端>"','run' -WindowStyle Hidden -RedirectStandardOutput "<云端>\logs\move-out.txt" -RedirectStandardError "<云端>\logs\move-err.txt"
```

看进度读 `<云端>\logs\move-cloud.log`，或者跑 `status`。每开始一步转述一句（`STEP` 行）。顺序是：服务器打底 → 放配置、拉镜像 → 传 Skill → 传表情包（她这时还在线）→ **停这台电脑上的她** → 传其余数据 → 改设置 → 起容器 → 接语音和记忆 → 放云端工作台 → 对账。

**断了不用慌**：网断、关机、窗口没了，重跑同一条 `run`，传完的批不再传。断的时候他又把她开起来了也没事：接着跑会先把她停掉，这期间动过的文件重传。

日志最后一行 `RESULT`：

- `RESULT need_human …`：退出码 3。启动器装的大脑，脚本停不了（还开着、在启动或者卡住都算），它会让他去启动器点「停止」并关掉「开机自启动」，做完重跑 `run`。
- `RESULT fail …`：退出码 1。照那句处理后重跑 `run`。
- `RESULT ok`：下一步。

## 5 扫码

小号的登录状态带不走，在服务器上要重新扫一次。他自己来：

> 打开桌面「云端大肥鱼工作台」，点「扫码登录」，二维码就在窗口里，用小号的手机 QQ 扫。手机提示账号有风险的话，先照手机上说的恢复，隔一会儿再扫。

SnowLuma 装的，先让他在桌面 QQ 里退出小号（同一个号两边登会互相踢）。

扫上以后让他点工作台「服务器重启后」那项的「补上」（重启服务器不用再扫码）。他用大号私聊一句「在吗」，她回了，再问一件以前跟她说过的事，答得上来就是记忆带过来了。

## 6 收尾

```powershell
& <python> -X utf8 "<S>\move_to_cloud.py" --dir <本机> --cloud-dir <云端> verify
```

人设、对话、消息、记忆、插件、表情包两边对账，服务器的数只会比这边多。

跟他说：

- 这台电脑可以关了。`<本机>` 还占着硬盘，用几天没问题想腾地方，照 `备份、换电脑和卸载.md` 卸掉**本机那套**（`uninstall.ps1 -Dir <本机>`），别卸 `<云端>`。
- 掉线提醒换成了盯服务器：这台电脑开着时才弹。电脑关着时她照常在线，只是掉线了你要自己发现。
- 以后都看「云端大肥鱼工作台」；桌面上「大肥鱼工作台」已经收起来了。

**记得告诉他**：桌宠（搬走以后桌宠连不上她了）、本机语音的声音换了（想要原来的声音，可以试 Breeze 在线版捏一个）。

## 退回这台电脑

搬完发现不想要（比如机房被 QQ 踢得太勤）：

```powershell
& <python> -X utf8 "<S>\move_to_cloud.py" --dir <本机> --cloud-dir <云端> undo
```

服务器上的容器撤掉（data 留着，不是 stop，不然服务器重启 NapCat 又起来抢小号），确认撤掉了才把这台电脑的开机自启、桌面入口放回去，把她和语音、记忆开起来。启动器装的要他自己去启动器点「启动」。服务器连不上时它会停下来不开本机：服务器确实不要了（退订、重装了）才加 `--server-gone`。

退回后想再搬一次，重跑 `run` 就行：服务器上那份 data 挪到 `data.old-日期`（不删），再传一遍。

**只在刚搬完用**：搬完以后云上新记住的事不会带回来。在云上住了一阵才想回来的，走 `云端.md` 的备份加「搬回这台电脑」那条路。

## 失败先查

| 看到 | 怎么办 |
|---|---|
| 镜像拉不下来 | 这时这台电脑的她还开着，没影响。照 `云端.md` C5.2 末尾换镜像地址 |
| 后台登不进去 | 他在网页上改过后台密码，`<本机>\private\backend.txt` 是旧的。让他把现在的账号密码写进去，重跑 `run` |
| 对账少了 | 看哪一项少，查清楚后跑 `run --fresh` 从头传一遍：服务器上那份停掉、挪到 `data.old-日期`（不删），这台电脑的数据没动过。别手动删 `move-cloud.json` |
| 语音或记忆那行不是 ok | 不影响聊天。照那行的提示补，在服务器上照 `云端.md` C9 只跑那一块；或者工作台点「补装」 |
| 大脑起不来 | `docker logs astrbot`。内存爆了就 `dmesg | grep -i oom`，2G 的机器确认 swap 开了 |
| 有插件没开 | 它的依赖在 Linux 上没装上。工作台「功能」页点「补装」，或者后台插件页看报错 |

## 别做的事

- 不替他买服务器、不替他点支付。
- 这台电脑的 `private` 不整个传：只带 `move_to_cloud.py` 里 `SECRETS` 列的那几个。桌宠的 key、SnowLuma 的文件留在这台电脑。
- 秘密不进命令行、不打印。服务器地址、QQ 号别念出来。
- 不在他说「搬」之前跑 `run`。
