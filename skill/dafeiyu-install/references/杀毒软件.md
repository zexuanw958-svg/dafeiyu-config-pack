# 杀毒软件拿走了文件：把工作目录加进信任区

什么时候读：`install-napcat.ps1`、`install-snowluma.ps1` 退出码 8；日志里有「拒绝访问」「解压失败」「移动versions目录失败」；或者某个程序刚装好就不见了。上一期评论区点赞最多的问题就是这个。

**别叫他关杀毒。** 小白不会关，关了再开文件还是会被删。做法是把大肥鱼的工作目录（只这一个文件夹，不是整个盘）加进杀毒软件的信任区，然后重跑刚才那个安装脚本：被拿走的文件会重新下、重新解压，**不用去隔离区恢复**。

## 先看是谁在管这台电脑

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\trust-folder.ps1" -Dir <工作目录> -Check
```

它会说 Windows 自带的杀毒（Defender）开没开、还有没有别家杀毒在跑。只算「开着、程序文件还在」的：安全中心里常有卸了没删干净、或者装了但关着的登记（10-28 测试机上就有一个程序早已不在的电脑管家，和一个关着的联想自带火绒），那些不用管。

两家都开着的（Defender 加一家别的），两边都要加。

## Windows 自带的杀毒（Defender）

最省事：跑脚本，他点一下「是」就加好了。先跟他说一句：「加了以后 Windows 自带的杀毒不再扫这个文件夹，里面只放大肥鱼的程序。」他同意再跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\trust-folder.ps1" -Dir <工作目录>
```

Windows 会弹「你要允许此应用对你的设备进行更改吗」，叫他点「是」。脚本会读回来核对，说「加好了」才算成。退出码 5：他点了「否」或者这个账户不是管理员；退出码 3：没加上。都可以照下面手动加。（10-28 在 ceshi 上实测脚本能加上、能读回；那次是从远程命令行跑的、本来就有管理员权限，没经过弹窗那一步。）

手动加（第 1–7 步 10-28 在 Windows 11 家庭版上点过，原字照抄）：

1. 点「开始」→「设置」。
2. 左边点「隐私和安全性」。
3. 右边点「Windows 安全中心」，再点「打开 Windows 安全中心」。
4. 左边点「病毒和威胁防护」。
5. 在「“病毒和威胁防护”设置」下面点「管理设置」（「实时保护」别动）。
6. 往下翻到「排除项」，点「添加或删除排除项」。
7. 弹「你要允许此应用对你的设备进行更改吗」，点「是」。
8. 点「添加排除项」→「文件夹」，选大肥鱼的工作目录，点「选择文件夹」。（第 8 步是微软的官方说法，我们没点到：测试时在第 7 步的弹窗没批准。）

## 火绒

（10-28 没实测：测试机上没有独立装的火绒。下面是火绒官方《6.0 用户操作手册》第 20–26 页的说法。）

打开火绒主界面 → 首页的「信任区」（或右上角菜单里的「信任区」）→ 添加信任 →「信任类型」选「文件夹」→ 选大肥鱼的工作目录 → 确定。

他截图发过来的界面跟这个对不上，就照截图上的字一步步带他找，别硬套。

联想电脑自带的「Lenovo Anti-Virus powered by Huorong」也是火绒的引擎，但界面在联想电脑管家里，入口没查到；碰到了让他截图，照截图带他找「信任区」或「白名单」。

## 腾讯电脑管家

（没实测，也没找到腾讯官方的说明；下面是别家软件帮助页里写的路线。）

打开腾讯电脑管家 →「病毒查杀」→「信任区」→「添加文件夹」→ 选大肥鱼的工作目录。

## 360 安全卫士、360 杀毒

（没实测；来源是几所学校、软件厂商的帮助文档，不是 360 官方最新版的说明。）

- 360 安全卫士：「木马查杀」→「信任区」→「已信任区」→「添加目录」→ 选工作目录。
- 360 杀毒：「设置」→「文件白名单」→「添加目录」→ 选工作目录。

## 加好以后

重跑刚才失败的那个脚本（`install-napcat.ps1` 或 `install-snowluma.ps1`），它会清掉没装成的残留、重新解压。重跑还是退出码 8：让他打开杀毒软件的「隔离区 / 恢复区」截图给你看，确认是不是还在拦、拦的是哪个文件，别让他点「恢复」，信任区加对了重跑就行。
