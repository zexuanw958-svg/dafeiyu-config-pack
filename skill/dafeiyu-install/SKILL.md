# 帮观众装大肥鱼（v0.4.1，2026-10-29）

你在帮一个可能完全不懂电脑的人，在他自己的 Windows 电脑上装一个 QQ 聊天机器人。整套流程以两次真机代部署、Vol.04 教程和 10-27、10-28 干净账户实测为准，细节在 `references/`。

**这一版的原则**：会影响结果的事都问他，每个选项的好处和缺点都摆出来，再说「拿不准就选哪个、为什么」。说明的责任在你，决定权在他。他一开口就说了的（「装 D 盘」「我要 SnowLuma」），对应那一问跳过，复述时标「按你说的」。

**能用现成脚本的步骤就用脚本，别自己现编命令。** 本 Skill 的 `scripts/` 里有：`probe.ps1`（体检）、`install-astrbot.ps1`（装 AstrBot）、`astr_setup.py`（接 DeepSeek、建平台、白名单、群里回复时 @ 不 @、看状态和日志）、`install-napcat.ps1` + `connect-napcat.ps1`（NapCat）、`install-snowluma.ps1` + `connect-snowluma.ps1`（SnowLuma；没装桌面 QQ 时先跑 `install-qq.ps1`）、`install-ollama.ps1`（本机记忆）、`install-ffmpeg.ps1`、`install-asr.ps1`（看视频；`-Plus` 加装听方言、听歌词的增强版）、`import-pack.ps1`（一块一块导入配置包）、`finish.ps1`（开机自启、掉线自救、桌面「大肥鱼工作台」；装在云服务器上的只放「云端大肥鱼工作台」）、`setup-pet.ps1`（可选：DSH 的桌宠 dsh-pet 也变成她，见 `references/桌宠.md`）、`workbench\`（工作台本体：本机小服务加一个小窗口；`cloud.py`、`cloud_remote.py` 是云端模式，经 `ssh` 看、修服务器上那套）、`workbench.ps1`（没有 Python 时的兜底静态页）、`diag.ps1`（「复制求助信息」：只读体检，打码后存到桌面）、`backup.ps1` + `restore.ps1` + `uninstall.ps1`（备份、换电脑还原、卸载）、`stop-instance.ps1`（另装一套时关旧的、以后换回来）、`trust-folder.ps1`（杀毒软件拿走文件时，把工作目录加进 Windows 自带杀毒的排除项；别家杀毒见 `references/杀毒软件.md`）。下面说的 `<S>` 就是这个 `scripts` 文件夹的完整路径，`<工作目录>` 是第 1 步他挑的文件夹。脚本可以重复跑，做过的会跳过；报错先看最后几行，再查 `references/坑.md`。

## 说话方式（对观众）

- 短句、人话。一次只让他做一件事，做完让他回一句「好了」。
- 不甩术语。非说不可的词第一次出现时带半句白话，比如「NapCat（帮机器人登 QQ 的程序）」。
- 他做不到、看不懂的，换个说法再讲一遍，别催。
- 出错了先自己查，查清楚再跟他说「卡在哪、我准备怎么修」，别把整段报错甩给他。
- 要等的地方先说在等什么、要下多大；时间按观众当前下载进度估，没把握就说「看网速」（「在下语音模型，约 3.3 GB，下载后会显示进度和剩余时间」）。
- 别人的程序稳不稳、好不好，你不打包票，只转述作者和官方的原话，说清出处。

## 秘密的规矩（对你）

- DeepSeek key、豆包 token、硅基流动 key、后台密码、QQ 号，全放在 `<工作目录>\private\` 的文本文件里。你自己读，**任何时候都不打印、不复述、不写进别的文件**。核对时只说「有没有、多长、开头是不是 sk-」。
- 要观众提供秘密时，不让他贴进对话框：建好空文件，用 `notepad <文件>` 打开，让他粘进去、保存、关掉。
- 回答文件、脚本里只写秘密文件的路径（`*_file`），不写值。
- 你自己的命令输出里万一出现了秘密，下一句提醒观众：录屏或截图前先打码。

## 必须停下来叫人的地方（你不替他点）

## 你自己的权限（DeepSeek Harness 的沙盒）

DSH 新对话默认是「工作区可写」（桌面版的权限菜单写「工作区内修改」，三档是「仅可查看／工作区内修改／完全权限」；命令行版叫「完全访问」）：你跑的命令在沙盒里，只能写当前工作区（一般是桌面），而且沙盒里 HTTPS 用不了（curl 报 `SEC_E_NO_CREDENTIALS`）、WMI 被拒（10-27 实测）；沙盒里起的程序权限级别低，SnowLuma 在这种权限下挂不上 QQ（它作者在 issue #563 里说的「低完整性问题」就是这个）。所以：

- 第 0 步体检可以直接在沙盒里跑，`probe.ps1` 会自己换备用读法，摘要第一行会写「体检是在 AI 帮手的沙盒里跑的」。
- 第 2 步起的安装脚本都要往 `<工作目录>` 写、要下载，**必须用完全访问跑**。运行时上下文里写着你现在的权限：已经是完全访问（Full access）就直接跑；还是工作区可写，就在复述那条消息里顺带说清两个办法，他回「开始」时一起定：
  1. 把对话框下方的权限切成「完全权限」（命令行版叫「完全访问」；桌面版切的时候会弹一个框，勾「我已了解风险」再点「启用完全权限」），装完再切回来（建议，省得点十几次确认）；
  2. 不切，你每跑一个安装脚本都申请一次提权（pwsh 工具的 `sandbox_permissions: danger-full-access`），他点「允许」。
- 别为了躲沙盒把东西装到桌面，也别把下载改成别的工具绕过去。

## 第 0 步：体检（只读，不装任何东西）

先跟他说一句「我先给你的电脑做个体检，只看不改，半分钟左右」，然后跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\probe.ps1"
```

输出分两段：`===JSON===` 给你读，`===摘要===` 是人话。读法和每个字段怎么用，在 `references/探测.md`。别把整段贴给他，转述两三句就够：系统、显卡、各盘还剩多少、网络通不通、装过什么。

纯技术的事按体检结果自己定，**不问他**（规则都在 `探测.md`）：从哪一步接着装；残留怎么修；本机语音用大模型还是小模型；有好几个实例、好几份 NapCat 时用哪个；下载走哪条线路。

## 第 1 步：问清楚再装（三问 + 复述）

**有提问卡片工具就用卡片问**（DSH 桌面版的 `ask_user_question`：每个选项一行，他点一下就行，录视频也清楚）。写法：

- 题干（`question`）只写一两句：要定什么，加「拿不准就选 X：理由」。体检数字（几个盘各剩多少）写成一句话，**别在题干里放表格**：卡片不认表格，会显示成一串竖线（10-28 实测）。
- 每个选项的好处、缺点写进它自己的 `description`，题干里别把选项再写一遍（10-28 桌面版 DSH 题干和选项各写一遍，录出来很乱）。
- 建议项排第一个、标签末尾加「（推荐）」；`header` 写两三个字，比如「装在哪」「1 登 QQ」。
- 问 ③ 五项放在同一张卡片里，一项一页（五个 question）。他点了选项卡片会自己翻到下一页。
- 没有卡片工具（命令行版）就照下面的样子发文字。

### 先看要不要单独问一句

只有一种情况先问：体检发现电脑上**已经有一个能在 QQ 上回话的机器人**，或者**别的路线装的机器人**（Docker、qq-bridge、MaiBot、单独用的 SnowLuma 等，判断条件见 `探测.md`「要不要先问」）。装到一半、还回不了话的不问，直接接着装，下面三问里已经定了的（比如工作目录）标「你现在用的」。

**先分清这个机器人是不是我们装的**：看体检里这个 AstrBot 实例（有好几个时先按 `探测.md`「好几个实例」挑定一个）的 `origin` 和 `defaultPersona`。体检读的是配置文件里写的默认人格名字，不用后台密码、不翻数据库：

| `origin` | 是什么 | 用哪种问法 |
|---|---|---|
| `dafeiyu` | 默认人格是大肥鱼，或者是本 Skill 装的、还没导人设 | 下面 A |
| `own` | 默认人格是他自己起名的，名字就是 `defaultPersona` | 下面 B，开口叫出这个名字 |
| `stock` | 别处装的，默认人格还是 AstrBot 自带的 `default` | 下面 B，不说名字 |
| 没有这个字段 | 体检读不到它的配置（Docker、藏得深、装法特殊） | 先问一句「这个机器人是你自己配的（有自己的名字和人设），还是照我们的视频装的大肥鱼？」，按他答的走 A 或 B |

**A. 我们装的**，这样问（〔 〕里按体检换）：

> 体检做完了。先问你一件事：你电脑上已经有一个大肥鱼了（〔AstrBot 版本〕，〔现在开着 / 现在没开〕）。〔我看到它有两个小毛病：……〕
> 1. 就用它，缺的补上，有毛病的我顺手修好。好处：聊天记录、记忆都留着，最快。
> 2. 不动它，另装一套新的。好处：旧的文件、聊天记录原样留着，新的从头配；缺点：两套不能同时开（用的是同一个小号、同一组端口），新的装到登小号那步，我先把旧的关掉（只关不删），以后想换回来我帮你切。
> 拿不准就选 1。回 1 或 2，有别的想法直接说。

他选 2：问 ② 建议一个新文件夹（比如旧的叫 `C:\dafeiyu` 就建议 `C:\dafeiyu2`），装 AstrBot 时换一个后台端口（`install-astrbot.ps1 -Port 6285`，旧的还开着）。旧的语音（Breeze）、记忆（Ollama）在跑的，问 ③ 里建议直接连它们、不重下；旧的装过表情包，回答文件里填 `meme_copy_from`（见 `导入配置包.md` 7.2），别自己拷文件夹。到第 4 步登小号之前，用 `stop-instance.ps1 -Dir <旧工作目录>` 关旧的（只停旧目录里的 AstrBot 和登 QQ 的程序，共用的语音、记忆不停），别自己写 `taskkill`。他以后想换回旧的：`stop-instance.ps1 -Dir <新的> -StartDir <旧的>`。

他选 1（或者体检认出是装到一半的），先跑一次 `& "<工作目录>\uv\tools\astrbot\Scripts\python.exe" -X utf8 "<S>\astr_setup.py" --dir <工作目录> status`（不到 1 秒；用 AstrBot 自带的 Python，系统的 `python` 常是应用商店的空壳；用启动器装的实例没有这个路径，用它实例里的 `venv\Scripts\python.exe`），它最后几行就是五项功能现在什么样（登 QQ 的程序、语音、记忆、角色、看视频，加表情包），问 ③ 里每项照它标「现在是 X」。记忆那行写「记不住事」（缺 key、本机模型没下、没指向记忆模型）、看视频那行写听声音「半截」「没装」的，不算装好，标成「现在是：装了但没接好」，问 ③ 里让他选怎么补，别照「已经有了」跳过（10-28 群友那台就是这样被跳过的）。**别自己写脚本去翻配置文件、数据库，也别为了确认去调语音、记忆接口**：10-28 桌面版 DSH 这么干，在他的工作区里留了 4 个脚本、多花 3 分钟。体检看到的别的实例、别的 NapCat 只报事实、不说「没用的」，装完再问删不删，规矩在 `探测.md`「旧东西怎么跟他说」。

**B. 他自己配的**（有自己的名字和人设），这样问：

> 体检做完了。先问你一件事：你电脑上已经有一个叫「〔咕咕嘎嘎〕」的机器人（〔AstrBot 版本〕，〔现在开着 / 现在没开〕），人设是你自己配的。〔`stock` 换成：你电脑上已经有一个能在 QQ 上回话的机器人（……），用的是 AstrBot 自带的默认人设，不是我们装的。〕
> 1. 整个变成大肥鱼：人设换成大肥鱼，聊天的几项设置（一句话拆成几条发、记多少轮对话、关掉深度思考这些）也换成大肥鱼那套，再补上你选的功能。好处：跟视频里一样。缺点：「〔咕咕嘎嘎〕」不再是默认人设了（她的人设还留在后台，没删）。改之前我先把现在的设置存一份，不喜欢就跟我说「退回去」，一条命令回到现在这样。
> 2. 只拿几样：「〔咕咕嘎嘎〕」的人设和聊天设置一点不动，只从大肥鱼这里挑你想要的：表情包、语音、记忆、看视频、群聊那几个插件。缺点：表情包是大肥鱼的图（蓝色小鲸鱼）；语音的声音描述是给大肥鱼写的，我得按「〔咕咕嘎嘎〕」重写一句，或者用她的录音克隆。改之前同样先存一份，能退回。
> 3. 不动它，另装一套大肥鱼：它的文件、聊天记录原样留着，大肥鱼从头配。缺点：两套不能同时开；新的也要登一个 QQ 小号，用它现在这个号的话，到登小号那步请你先把「〔咕咕嘎嘎〕」关掉（只关不删）。
> 拿不准就选 〔`own`：2。你的角色原样留着，想要的功能照样加；哪天想整个换成大肥鱼，再换也行 ｜ `stock`：1。它现在用的是 AstrBot 自带的默认人设，换成大肥鱼不丢东西，改之前也会先存一份〕。回 1、2 或 3。

为什么这么推荐：`own` 的人花过心思配自己的角色，整个换掉是他最可能后悔的一种，「只拿几样」不碰他的角色、功能照样能加；`stock` 没有自己的角色可丢，整个换成大肥鱼最省事。两种都先存快照，选错了能退回。

他选 1（整个变成大肥鱼）：
1. 他的 AstrBot 不是本 Skill 装的，先建工作目录（问 ② 照常问；只放设置文件、配置包和要下载的东西），照 `基础-AstrBot和DeepSeek.md`「已经用启动器装过」把 `url`、他的后台账号、密码写进 `<工作目录>\private\backend.txt`（密码让他用记事本粘；他忘了就照那节重置），再写好 `<工作目录>\answers.json`（`导入配置包.md` 7.2，先有地址和账号密码那三项就能存快照）。
2. **改任何设置之前**先存快照：`powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\import-pack.ps1" -Dir <工作目录> -Snapshot`（他自己装的 AstrBot 找不到自带的 Python，就加 `-Python <他那套的 python.exe>`）。**成功**：最后一行是 `SNAPSHOT <路径>`，`<工作目录>\private\snapshots\original.json` 在。没成功就停下来查，不往下改。
3. 接着照 A 的「他选 1」：跑 `status`、问 ③ 标「现在是 X」、第 6 步跑 core。白名单他原来开着的不动；原来没开的照第 5 步问他（`whitelist` 会用他自己的 QQ 平台名，不会写成「大肥鱼」）。
4. 跟他说一句怎么退回。他说「退回去」就跑 `import-pack.ps1 -Dir <工作目录> -Restore`（回到第一次动之前；只退最近一次就加 `-From <那次的快照文件>`）。**成功**：最后一行 `RESULT restore=ok`，`status` 的「4 角色」那行又是他原来的名字；让他在 QQ 里先发 `/reset` 再聊。大肥鱼的人设留在后台人格列表里，只是不再是默认；这次装的配置包插件关掉、不卸载。

## 加功能的规矩（第 7 步）

上一期很多人卡在「表情包下不动，后面全停」。所以：

- **主路只到「能聊天」**：AstrBot、DeepSeek、协议端、白名单。这几样没好，停下来修；好了就先让他聊上，再加别的。
- **其余每一项都是单独的**：语音、记忆、表情包、看视频、换角色，哪一项失败都不挡别的。失败的那项跟他说一句人话（「语音模型这会儿下不动，我先跳过，别的照装，等会儿或者明天在工作台点一下就能补上」），接着装下一项，最后在复述里列出「还差哪项没装上、怎么补」。
- **下载慢**：uv、Python、AstrBot 依赖、ffmpeg、bge-m3、看视频的识别模型（SenseVoice）优先用国内源；普通 GitHub 文件按加速列表依次试，只有 Ollama 安装包、GitHub 大模型包先测速。接入公共下载器或 Breeze 下载器的文件会保留半截续传，每 15 秒报已下体积和剩余时间；总大小未知就报体积和速度，你照着转述。连接最多等 12 秒；持续 45 秒低于约 30 KB/s 会判为低速，重试后仍失败才换源，不是 45 秒内一定换源。地址不支持续传才清掉半截重下，校验失败的文件也会删掉重下。全都不行，别让他去折腾网络设置，按上一条跳过这一项。`install-asr.ps1` 全没下动时退出码 2、打出浏览器下载地址，照 `看图看视频.md`「本机识别下不动」给他三条路挑。
- **一项一项告诉他进度**：开始前说要下多大、大概多久；装好一项说一声。导入工具每块最后有一行 `RESULT <块>=ok|partial|fail|skip reason=… next=…`，照它转述，`next` 就是怎么补。记忆那块（或 `setup-pet.ps1`）输出里有 `MIGRATE private-memories` 的，是他以前在 QQ 私聊里让她记住的事要搬到新位置：你替他跑 `astr_setup.py ... memory-migrate` 预览、`memory-migrate apply` 搬（`references/桌宠.md`「旧记忆搬家」），搬完说一句就行。
- **大件放后台**：几百 MB 以上的下载（表情包、本机语音模型、Ollama）用 `Start-Detached` 放后台跑、日志写进 `<工作目录>\logs\`，你每半分钟读一次日志转述进度，他可以一边等一边跟她聊。别把一个可能跑一个多小时的下载放在前台等，会被你自己的超时掐断。

## 验收（第 9 步）

依次让他做、你在后台日志里核对：

1. 大号私聊小号「在吗」→ 她回话，语气是大肥鱼（或他的角色）的。之前聊过的先发 `/reset`。
2. 选了群的：在群里 @ 她一句 → 她回，选了 @ 的开头会 @ 他（她回的是语音时不带 @，QQ 语音消息带不了）。
3. 选了语音的：多聊几句，三条里大约有一条是语音（豆包要等 15–35 秒，Breeze 几秒）。收到语音以后问她「你刚才那条语音说的啥」，她说得出来才算过；说「我只会打字」的，看后台插件列表里 `astrbot_plugin_dafeiyu_clean` 是不是 v0.2.0 以上。
4. 表情包：多聊几句会配图；群里也会配（配置包 `7121c0c` 以后的版本才行）。
5. 选了记忆的：跟她说「记住，我家猫叫团子」，发 `/reset`，再问她「我家猫叫什么」。先跟他讲清楚记忆怎么存（别等他试失败了才说）：平时聊天攒满 10 轮（一问一答算一轮）她总结一次存进长期记忆；发 `/reset` 清空聊天时，没攒满的那几轮会先存进去再清（配置包自带的「清空不失忆」插件），所以清完再问也记得，发完 `/reset` 等十来秒再问；想让她当场记住，就说「记住……」。她想起旧事是拿眼前这句话去找的：泛泛地问「你还记得我吗」不一定想得起来，问到具体的事（「我家猫叫什么」）就想起来了，这不是记忆坏了。清完等过十来秒还问不出来，看后台插件列表里有没有 `astrbot_plugin_dafeiyu_resetkeep`（老的配置包没有，跑 `import-pack.ps1 -Only plugins` 补上）。10 轮是插件默认，想改在后台插件设置「总结触发轮次」里改（1–100）。
6. 私聊发一张图，问「图里是什么」；选了看视频的，再发一段 10–30 秒的视频（`看图看视频.md`「验收」）。
7. 掉线自救：选 A 的关掉 NapCat 窗口，双击桌面的「大肥鱼掉线-双击扫码」，能自己登回来（或弹码扫一下）；选 B 的双击桌面的「大肥鱼掉线-双击重登」（或在工作台点「重新登 QQ」）：它会把 SnowLuma 和桌面 QQ 重新打开，他在 QQ 窗口里点登录或扫码。

全部通过，跟他说一句完事了（只拿几样的说「〔他的角色名〕还是原来的她，新加了：……」，别说「她已经是大肥鱼了」），再提醒几件事：DeepSeek Harness 的权限记得切回「工作区可写」；电脑开着她才在线；启动器装的大脑，启动器里「开机自启动」那三个开关开了没有（没开，重启电脑后她不会回来），托盘里的启动器别点退出；他选了不开白名单的，再说一句「谁 @ 她都能用，花的是你的 DeepSeek 余额，想关随时说」；小号偶尔被 QQ 踢下线是正常的，桌面工作台里点一下就能重新登；选了本机语音或记忆的，打游戏前在工作台点「打游戏模式」，打完点恢复（`references/记忆.md`「对电脑的影响、打游戏」）；后台密码在 `<工作目录>\private\backend.txt`，想改成自己记得住的，改完把新密码写回这个文件。没装上的项，再说一遍怎么补。体检报了装着桌宠插件 dsh-pet、还没接成她（`agents.dshPet.installed` 真、`linked` 假）的，最后问一句要不要让桌宠也变成她（话术和代价在 `references/桌宠.md`「什么时候提」）；没装 dsh-pet 的不提，也不劝他装。选了群的再说一句：群里她主要回 @ 她的消息，偶尔自己插话；群里发语音没法同时 @ 她，想让她回那条语音，发完再 @ 她一句；「回谁要不要 @ 那个人」以后在工作台「群里插话」下面改。

## 装完以后他回来找你

- 「补装表情包、语音、记忆、看视频」：照「加功能的规矩」跑 `import-pack.ps1 -Only <那块>`（要下大文件的先跑对应的 install 脚本）。
- 「让她进群」「再加个群」：先让他用大号把小号拉进群，群号粘进 `private\group.txt`（一行一个），跑 `astr_setup.py ... whitelist`（记忆已经是「私聊和桌宠共用」那种的，它顺手把群加进记忆的强制隔离和记忆白名单，这个群的事她单独记）；没问过的话问一句回谁要不要 @（`group-reply`），并告诉他群里发语音要发完再 @ 她。不进白名单的群，她看到 @ 也不回。
- 「她说话太……」「这个词别老说」「语气改改」（人设大方向没毛病，只想调语气、用词）：别让他去别的对话改好再复制过来。问清哪里不舒服（最好贴一两句她的原话），在 `<配置包>\persona\大肥鱼.md`（他换了自己的角色就是他那份）里只改说话方式那几条，改动给他看，他说行再跑 `import-pack.ps1 -Dir <工作目录> -Only core`（几秒，改之前自动存快照）。下一句就用新的人设，不用 `/reset`；聊几句还是老腔调（聊天记录里旧的说法会把她往回带），再发一次 `/reset`，清之前没存的那几轮会先存进长期记忆，不会忘事。改坏了用 `-Restore -From <这次的快照>` 退回。第 1 步选了「只拿几样」的，人设是他自己原来的，导入工具不碰，照改好的文字带他在后台「人格设定」里改。
- 「退回去」「换回原来那样」（第 1 步 B 里选了整个变成大肥鱼或只拿几样的）：`import-pack.ps1 -Dir <工作目录> -Restore`，见第 1 步 B「他选 1」第 4 条。
- 「她不回话了」：先让他双击桌面的掉线自救，或者在工作台点修复；还不行再看日志。
- 装在云服务器上的（工作目录的 `private\cloud.txt` 写着服务器）：掉线扫码、补装、看日志、备份、求助信息都先让他用桌面「云端大肥鱼工作台」；你要动服务器，照 `references/云端.md` 用 `ssh` 去做。他桌面上还是两个 `.cmd`、没有工作台的（老版本装的），跑一次新 Skill 的 `finish.ps1 -Dir <工作目录>` 就放上了。
- 「让桌宠也变成她」「桌宠也要是大肥鱼」：读 `references/桌宠.md`（他没装 dsh-pet 就告诉他先在 DSH 的插件管理里装，不替他装）。「桌宠变回原来那样」：`setup-pet.ps1 -Dir <工作目录> -Remove`。
- 「备份一下」「换电脑了」「重装系统前」「不想要了」「卸干净」：读 `references/备份、换电脑和卸载.md`。卸载一定先列清单、他回「确认」才删。

## 别做的事

- 不打开 AstrBot 的「操作电脑」能力，不给她执行命令、读写文件的工具。
- 不改系统代理、防火墙、网络设置（WorkBuddy 自己弹的防火墙框，点「取消」也不影响，10-25 实测）。
- SnowLuma：他没亲口说「同意」之前不加 `-AcceptAgreements`；不改 SnowLuma 包里的任何文件；不把它打包转给别人（它的协议不许）。
- 不把群里插话概率调到 0.1 以上，插得多容易被风控。

## 怎么装这个 Skill

他先装好 DeepSeek Harness（或 WorkBuddy），新开对话粘这一句（资料文档和仓库 README 里都有）：

> 帮我装一个叫 dafeiyu-install 的技能，装好直接用它帮我装大肥鱼：从 https://gh.dpik.top/https://github.com/zexuanw958-svg/dafeiyu-config-pack/releases/latest/download/dafeiyu-install.zip 下载压缩包（下不动就去掉开头的 https://gh.dpik.top/ 再试），解压后把里面的 dafeiyu-install 文件夹放进你读技能的文件夹（DeepSeek Harness 是 %USERPROFILE%\.agents\skills\，WorkBuddy 是 %USERPROFILE%\.workbuddy\skills\，没有就新建；里面已经有 dafeiyu-install 的，先把旧的挪到别处）。放好后读一遍它的 SKILL.md，照着开始。

- 10-28 DeepSeek Harness 桌面版实测：两三分钟装好接着体检，点一次「允许一次」（往工作区外面写文件要提权）。它的沙盒里 `curl`、`Invoke-WebRequest` 连 HTTPS 会失败（SEC_E_NO_CREDENTIALS），`node` 的 fetch 能下，它会自己换着试。
- 技能文件夹里别留改了名的旧副本（`dafeiyu-install.旧-…` 这种）：Agent 会把两份同名 Skill 都读进来。旧的挪到 `<工作目录>\旧版\` 或者别处。
- WorkBuddy 放 `%USERPROFILE%\.workbuddy\skills\`；它认不认这种 SKILL.md，还没从头测过。

## 更新这个 Skill（他说「更新大肥鱼」「更新一下 Skill」，或者工作台提示有新版）

新版发在 GitHub `zexuanw958-svg/dafeiyu-config-pack` 的 Releases，最新一版固定在 `https://github.com/zexuanw958-svg/dafeiyu-config-pack/releases/latest/download/` 下面两个文件：`skill-version.json`（版本号、`notes` 改了什么、`reimport` 要重新导入哪几块）和 `dafeiyu-install.zip`（里面带同一版的配置包）。前面加 `https://gh.dpik.top/` 这类加速地址也能下。

**先让他用工作台**：「更新」页「安装 Skill 和工作台」那行点「一键更新」，它自己下载、备份、换 Skill 和配置包、重跑收尾、重开工作台，半分钟左右；要重新导入的，它更新完会告诉他怎么跟你说。工作台版本低于 1.1（测试版 1 装的）没有这个按钮，才照下面手动换：

1. 查新版：下 `skill-version.json`，跟本 Skill 的 `version.json` 比版本号。跟他说一句新版改了什么（`notes`），他点头再更新。
2. 下载：先 `. "<S>\common.ps1"`，再 `Get-GitHubFile -Url https://github.com/zexuanw958-svg/dafeiyu-config-pack/releases/latest/download/dafeiyu-install.zip -OutFile <工作目录>\downloads\dafeiyu-install-新版.zip -MinBytes 100000`（会自己走加速地址）。解压到 `<工作目录>\downloads\skill-新版\`，确认有 `dafeiyu-install\SKILL.md`、`dafeiyu-install\version.json` 和 `dafeiyu-install\pack\dafeiyu-config-pack\tools\import_dafeiyu.py`。
3. 备份：建 `<工作目录>\旧版\<月日-时分>\`，把旧的技能文件夹（WorkBuddy 也装了的话那份一起）、`<工作目录>\dafeiyu-config-pack`、`<工作目录>\tools` 拷进去。
4. 换：删掉技能文件夹里旧的 `dafeiyu-install`，放新的；`<工作目录>\dafeiyu-config-pack` 换成新 Skill 里的 `pack\dafeiyu-config-pack`，旧包里有 `voice\breeze`（做声音留的参考音和原录音）的拷回新包同一位置；跑新 Skill 的 `finish.ps1 -Dir <工作目录>`（换工作台、记下新版本号，开机自启和快捷方式照旧）。
5. 要不要重新导入：只按 `reimport` 来（比如有 `plugins` 就跑 `import-pack.ps1 -Dir <工作目录> -Only plugins`）；空的就不导，人设、记忆、聊天记录都不动。他自己改过人设的，导 `core` 前先问他。
6. 让他打开工作台看一眼全绿，再私聊她一句。`旧版` 里的备份，等他用几天没问题再问他删不删。

**装在云服务器上的**（工作目录里有 `private\cloud.txt`、没有 AstrBot）：「一键更新」照样能用，它除了换这台电脑上的 Skill 和工作台，还把新版整包传到服务器，换掉 `/opt/dafeiyu/kit/dafeiyu-install`（旧的挪进 `/opt/dafeiyu/old/`），大约一分钟；工作台的版本取这台电脑和服务器两份里旧的那个，服务器那份落后了也会提示更新。要重新导入的块在服务器上跑（`references/云端.md` C9）。手动换的：上面第 3、4 步里云端工作目录没有 `dafeiyu-config-pack`，跳过那部分；换完技能文件夹跑新 Skill 的 `finish.ps1 -Dir <工作目录>`（老版本装的云端，这一步顺手放上「云端大肥鱼工作台」），再照 C6 把新 Skill 传上服务器。
