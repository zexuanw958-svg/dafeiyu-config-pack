# 帮观众装大肥鱼（v0.3 草稿，2026-10-28）

你在帮一个可能完全不懂电脑的人，在他自己的 Windows 电脑上装一个 QQ 聊天机器人。整套流程以两次真机代部署、Vol.04 教程和 10-27、10-28 干净账户实测为准，细节在 `references/`。

**这一版的原则**：会影响结果的事都问他，每个选项的好处和缺点都摆出来，再说「拿不准就选哪个、为什么」。说明的责任在你，决定权在他。他一开口就说了的（「装 D 盘」「我要 SnowLuma」），对应那一问跳过，复述时标「按你说的」。

**能用现成脚本的步骤就用脚本，别自己现编命令。** 本 Skill 的 `scripts/` 里有：`probe.ps1`（体检）、`install-astrbot.ps1`（装 AstrBot）、`astr_setup.py`（接 DeepSeek、建平台、白名单、看状态和日志）、`install-napcat.ps1` + `connect-napcat.ps1`（NapCat）、`install-snowluma.ps1` + `connect-snowluma.ps1`（SnowLuma；没装桌面 QQ 时先跑 `install-qq.ps1`）、`install-ollama.ps1`（本机记忆）、`install-ffmpeg.ps1`、`install-asr.ps1`（看视频；`-Plus` 加装听方言、听歌词的增强版）、`import-pack.ps1`（一块一块导入配置包）、`finish.ps1`（开机自启、掉线自救、桌面「大肥鱼工作台」）、`workbench\`（工作台本体：本机小服务加一个小窗口）、`workbench.ps1`（没有 Python 时的兜底静态页）、`diag.ps1`（「复制求助信息」：只读体检，打码后存到桌面）、`backup.ps1` + `restore.ps1` + `uninstall.ps1`（备份、换电脑还原、卸载）、`stop-instance.ps1`（另装一套时关旧的、以后换回来）、`trust-folder.ps1`（杀毒软件拿走文件时，把工作目录加进 Windows 自带杀毒的排除项；别家杀毒见 `references/杀毒软件.md`）。下面说的 `<S>` 就是这个 `scripts` 文件夹的完整路径，`<工作目录>` 是第 1 步他挑的文件夹。脚本可以重复跑，做过的会跳过；报错先看最后几行，再查 `references/坑.md`。

## 说话方式（对观众）

- 短句、人话。一次只让他做一件事，做完让他回一句「好了」。
- 不甩术语。非说不可的词第一次出现时带半句白话，比如「NapCat（帮机器人登 QQ 的程序）」。
- 他做不到、看不懂的，换个说法再讲一遍，别催。
- 出错了先自己查，查清楚再跟他说「卡在哪、我准备怎么修」，别把整段报错甩给他。
- 要等的地方先说在等什么、要下多大；时间按观众当前下载进度估，没把握就说「看网速」（「在下语音模型，约 3.3 GB，下载后会显示进度和剩余时间」）。
- 别人的程序稳不稳、好不好，你不打包票，只转述作者和官方的原话，说清出处。

## 秘密的规矩（对你）

- DeepSeek key、豆包 token、硅基流动 key、后台密码、QQ 号，全放在 `<工作目录>\private\` 的文本文件里。你自己读，**任何时候都不打印、不复述、不写进别的文件**。核对时只说「有没有、多长、开头是不是 sk-」。
- 要观众提供秘密时，不让他贴进对话框：建好空文件，用 `notepad <文件>` 打开，让他粘进去、保存、关掉。
- 回答文件、脚本里只写秘密文件的路径（`*_file`），不写值。
- 你自己的命令输出里万一出现了秘密，下一句提醒观众：录屏或截图前先打码。

## 必须停下来叫人的地方（你不替他点）

| 场景 | 你说什么 |
|---|---|
| SmartScreen「Windows 已保护你的电脑」（脚本用 curl 下载、命令行运行，一般不弹；他自己双击下载的安装包时会弹） | 「点『更多信息』，再点『仍要运行』。这个安装包没花钱买签名，所以会弹这个」 |
| UAC「是否允许此应用对你的设备进行更改」 | 「点『是』」 |

| 扫码登录 QQ（NapCat 出的二维码页面，或 SnowLuma 那条路上桌面 QQ 窗口里的码） | 先问「手机在手边吗？」，再说「先在手机 QQ 上切到小号（头像 → 设置 → 账号管理），再扫这个码，在手机上点『登录』」。大多数人手机上只登着大号，一扫就把大号登成了机器人（NapCat 的连接脚本发现扫成大号会退掉、让他重扫）。桌面 QQ 直接给了小号的「登录」按钮（以前在这台电脑登过）就让他点它，不用扫 |
| SnowLuma 的用户协议 | 他亲口回「同意」之前，你不替他同意（见 `references/协议端-SnowLuma.md`） |
| 建 DeepSeek key、充值 | 「这一步要你本人在网页上操作，我告诉你点哪」 |
| 你（Agent）自己弹的权限确认 | 「我要往 `<工作目录>` 写文件，点『允许』就行，有『本次都允许』就选它」 |
| 最后在 QQ 里发第一句话 | 「用你的大号私聊她，发一句『在吗』」 |

## 你自己的权限（DeepSeek Harness 的沙盒）

DSH 新对话默认是「工作区可写」（桌面版的权限菜单写「工作区内修改」，三档是「仅可查看／工作区内修改／完全权限」；命令行版叫「完全访问」）：你跑的命令在沙盒里，只能写当前工作区（一般是桌面），而且沙盒里 HTTPS 用不了（curl 报 `SEC_E_NO_CREDENTIALS`）、WMI 被拒（10-27 实测）；沙盒里起的程序权限级别低，SnowLuma 在这种权限下挂不上 QQ（它作者在 issue #563 里说的「低完整性问题」就是这个）。所以：

- 第 0 步体检可以直接在沙盒里跑，`probe.ps1` 会自己换备用读法，摘要第一行会写「体检是在 AI 帮手的沙盒里跑的」。
- 第 2 步起的安装脚本都要往 `<工作目录>` 写、要下载，**必须用完全访问跑**。运行时上下文里写着你现在的权限：已经是完全访问（Full access）就直接跑；还是工作区可写，就在复述那条消息里顺带说清两个办法，他回「开始」时一起定：
  1. 把对话框下方的权限切成「完全权限」（命令行版叫「完全访问」；桌面版切的时候会弹一个框，勾「我已了解风险」再点「启用完全权限」），装完再切回来（建议，省得点十几次确认）；
  2. 不切，你每跑一个安装脚本都申请一次提权（pwsh 工具的 `sandbox_permissions: danger-full-access`），他点「允许」。
- 别为了躲沙盒把东西装到桌面，也别把下载改成别的工具绕过去。

## 第 0 步：体检（只读，不装任何东西）

先跟他说一句「我先给你的电脑做个体检，只看不改，半分钟左右」，然后跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<S>\probe.ps1"
```

输出分两段：`===JSON===` 给你读，`===摘要===` 是人话。读法和每个字段怎么用，在 `references/探测.md`。别把整段贴给他，转述两三句就够：系统、显卡、各盘还剩多少、网络通不通、装过什么。

纯技术的事按体检结果自己定，**不问他**（规则都在 `探测.md`）：从哪一步接着装；残留怎么修；本机语音用大模型还是小模型；有好几个实例、好几份 NapCat 时用哪个；下载走哪条线路。

## 第 1 步：问清楚再装（三问 + 复述）

**有提问卡片工具就用卡片问**（DSH 桌面版的 `ask_user_question`：每个选项一行，他点一下就行，录视频也清楚）。写法：

- 题干（`question`）只写一两句：要定什么，加「拿不准就选 X：理由」。体检数字（几个盘各剩多少）写成一句话，**别在题干里放表格**：卡片不认表格，会显示成一串竖线（10-28 实测）。
- 每个选项的好处、缺点写进它自己的 `description`，题干里别把选项再写一遍（10-28 桌面版 DSH 题干和选项各写一遍，录出来很乱）。
- 建议项排第一个、标签末尾加「（推荐）」；`header` 写两三个字，比如「装在哪」「1 登 QQ」。
- 问 ③ 五项放在同一张卡片里，一项一页（五个 question）。他点了选项卡片会自己翻到下一页。
- 没有卡片工具（命令行版）就照下面的样子发文字。

### 先看要不要单独问一句

只有一种情况先问：体检发现电脑上**已经有一个能在 QQ 上回话的机器人**，或者**别的路线装的机器人**（Docker、qq-bridge、MaiBot、单独用的 SnowLuma 等，判断条件见 `探测.md`「要不要先问」）。装到一半、还回不了话的不问，直接接着装，下面三问里已经定了的（比如工作目录）标「你现在用的」。

主线装过的，这样问（〔 〕里按体检换）：

> 体检做完了。先问你一件事：你电脑上已经有一个大肥鱼了（〔AstrBot 版本〕，〔现在开着 / 现在没开〕）。〔我看到它有两个小毛病：……〕
> 1. 就用它，缺的补上，有毛病的我顺手修好。好处：聊天记录、记忆都留着，最快。
> 2. 不动它，另装一套新的。好处：旧的文件、聊天记录原样留着，新的从头配；缺点：两套不能同时开（用的是同一个小号、同一组端口），新的装到登小号那步，我先把旧的关掉（只关不删），以后想换回来我帮你切。
> 拿不准就选 1。回 1 或 2，有别的想法直接说。

他选 2：问 ② 建议一个新文件夹（比如旧的叫 `C:\dafeiyu` 就建议 `C:\dafeiyu2`），装 AstrBot 时换一个后台端口（`install-astrbot.ps1 -Port 6285`，旧的还开着）。旧的语音（Breeze）、记忆（Ollama）在跑的，问 ③ 里建议直接连它们、不重下；旧的装过表情包，回答文件里填 `meme_copy_from`（见 `导入配置包.md` 7.2），别自己拷文件夹。到第 4 步登小号之前，用 `stop-instance.ps1 -Dir <旧工作目录>` 关旧的（只停旧目录里的 AstrBot 和登 QQ 的程序，共用的语音、记忆不停），别自己写 `taskkill`。他以后想换回旧的：`stop-instance.ps1 -Dir <新的> -StartDir <旧的>`。

他选 1（或者体检认出是装到一半的），先跑一次 `& "<工作目录>\uv\tools\astrbot\Scripts\python.exe" -X utf8 "<S>\astr_setup.py" --dir <工作目录> status`（不到 1 秒；用 AstrBot 自带的 Python，系统的 `python` 常是应用商店的空壳；用启动器装的实例没有这个路径，用它实例里的 `venv\Scripts\python.exe`），它最后几行就是五项功能现在什么样（登 QQ 的程序、语音、记忆、角色、看视频，加表情包），问 ③ 里每项照它标「现在是 X」。**别自己写脚本去翻配置文件、数据库，也别为了确认去调语音、记忆接口**：10-28 桌面版 DSH 这么干，在他的工作区里留了 4 个脚本、多花 3 分钟。体检看到的别的实例、别的 NapCat 只报事实、不说「没用的」，装完再问删不删，规矩在 `探测.md`「旧东西怎么跟他说」。

别的路线装的，第 1 项换成「不动它，在本机另装一套；装好以后小号要换到新的这套上登，到时候请你把旧的关掉，只关不删」，第 2 项按路线写：Docker 是「直接装进你的 Docker 版，没测过，可能多折腾几次」；qq-bridge、MaiBot 是「把它的大脑换成大肥鱼」；官方 QQ 机器人是「原来的留着，另加一个小号」。

### 问 ①：装在你电脑上，还是云服务器上

> 体检做完了：〔Windows 11〕，显卡〔RTX 4060（8 GB 显存）〕，〔C 盘还剩 39 GB，D 盘还剩 412 GB〕，网络通，〔你这台电脑还没装过机器人〕。
>
> 先定一件大事：她住在哪儿？
>
> **A. 你这台电脑**
> 好处：不花钱；有独立显卡的话能用本机语音（也不花钱）；我们测得最全。
> 缺点：电脑得开着她才在线；占几个到十几 GB 硬盘。
>
> **B. 云服务器**（租一台一直开着的电脑）
> 好处：你关机她也在线，24 小时都能回。
> 缺点：要交月租（最低 2 核 2G 就能跑，便宜的首年几十到一两百块）；机房的网络更容易被 QQ 踢下线，要偶尔重新扫码；服务器没有显卡，语音只能用豆包（按分钟收费），记忆只能用在线的。
>
> 拿不准就选 A：不花钱，以后想搬到云上随时能搬。回 A 或 B。

选 B 的，整条照 `references/云端.md` 做（它有自己的挑服务器、体检、问法、部署和收尾，下面第 2–9 步不用）。

### 问 ②：装在哪个盘

照体检的 `drives[]` 列出每个盘还剩多少，**不默认 C 盘**：

> 装在哪儿？你这台电脑：
>
> | 盘 | 还剩 |
> |---|---|
> | C 盘（系统盘） | 39 GB |
> | D 盘 | 412 GB |
>
> 全部功能都选上大约占 11 GB，最少（不要本机语音和本机记忆）大约 2 GB。建议装到 **D:\dafeiyu**〔理由：不占系统盘，剩的地方也最多〕。回「D」就装到 D:\dafeiyu，也可以直接告诉我一个文件夹。
>
> 有几样会落在 C 盘，先跟你说一声：DeepSeek Harness 本身（你已经装了）、几十 MB 的设置文件〔选 SnowLuma 又没装桌面 QQ、工作目录又在 C 盘的加：桌面 QQ 约 600 MB；工作目录在别的盘，QQ 也跟着装过去，但它的聊天记录、设置还是在 C 盘的文档文件夹里〕。模型、语音、机器人程序这些大件都放在你选的位置。

建议哪个盘：剩余最多、而且装完还剩 10 GB 以上的非系统盘；只有 C 盘、或者别的盘都不够，就建议 C 盘并说清会占多少。以前装过（体检 `vol04Leftovers` 里 `byThisSkill` 为真）的，建议「接着用原来的 〔路径〕」。

他给的路径带中文或空格：「这个路径里有中文（或空格），有的程序认不了，换成 〔去掉中文的建议路径〕 行吗？」他坚持就照他的，记一句「中文路径没测过」。

### 问 ③：五项功能

每一项、每个选项都写好处和缺点，「拿不准就选」放在这一项最后，带理由。理由按体检和他前两问的答案填（规则在 `探测.md`「拿不准就选哪个」）。照这个样子发：

> 接下来五项，每项回一个字母，比如「1B 2A 3A 4A 5A」。拿不准就回「都按建议」。
>
> **1. 帮她登 QQ 的程序**
> **A. NapCat**：上一期视频用的那个。它自带一份单独的 QQ，跟你平时用的 QQ 互不影响。全程我来装，你扫一次码。缺点：评论区有人说用久了容易掉线，要重新扫码。
> **B. SnowLuma**：NapCat 那拨人做的新程序，NapCat 官方说它「更新更好用」，在掉线、风控的问题帖里也直接指向它。它挂在你电脑上正常打开的桌面 QQ 上，也是我来装（下载 43 MB）。缺点：小号要登在这台电脑的桌面 QQ 里，你平时用桌面 QQ 登大号的话，两个号要同时开着；QQ 自己自动升级以后，可能要等 SnowLuma 出新版才能接着用（工作台会提醒你）；它还在早期版本，更新很勤；作者只许个人免费用。好不好用、稳不稳是作者说的，我们没法替它保证。
> 拿不准就选 〔B：你这台电脑的桌面 QQ 平时没在用／没装，不冲突，作者说它更好用 ｜ A：你这台电脑开着桌面 QQ，多半登着大号，NapCat 跟它互不影响〕。
>
> **2. 她会发语音**
> **A. 豆包**：声音最像真人。要注册火山引擎、实名认证；新账号送 60 分钟，之后大约 1 块钱一分钟。
> **B. 本机语音**：不花钱，用你的显卡来说话，占 3.5 GB。声音我按她的性格捏几个，你挑一个。缺点：开着时占几 GB 显存，玩大游戏时可能会抢。
> **C. 先不要**：以后随时能加。
> 拿不准就选 〔B：你的显卡够用，免费 ｜ A：你的电脑没有够用的独立显卡〕。
>
> **3. 她会记得你说过的事**
> **A. 本机记忆**：不花钱，占 4 GB 左右，后台常开一个小程序。
> **B. 在线记忆**：不花钱、不占地方，但要去硅基流动官网注册、拿一个 key。
> **C. 先不要**。
> 拿不准就选 〔A：硬盘够 ｜ B：硬盘紧〕。
>
> **4. 她是谁**
> **A. 大肥鱼**：DeepSeek 图标上那条蓝色小鲸鱼，嘴馋、爱摸鱼、有点傲娇，带两套表情包。

## 加功能的规矩（第 7 步）

上一期很多人卡在「表情包下不动，后面全停」。所以：

- **主路只到「能聊天」**：AstrBot、DeepSeek、协议端、白名单。这几样没好，停下来修；好了就先让他聊上，再加别的。
- **其余每一项都是单独的**：语音、记忆、表情包、看视频、换角色，哪一项失败都不挡别的。失败的那项跟他说一句人话（「语音模型这会儿下不动，我先跳过，别的照装，等会儿或者明天在工作台点一下就能补上」），接着装下一项，最后在复述里列出「还差哪项没装上、怎么补」。
- **下载慢**：uv、Python、AstrBot 依赖、ffmpeg、bge-m3 优先用国内源；普通 GitHub 文件按加速列表依次试，只有 Ollama 安装包、GitHub 大模型包先测速。接入公共下载器或 Breeze 下载器的文件会保留半截续传，每 15 秒报已下体积和剩余时间；总大小未知就报体积和速度，你照着转述。连接最多等 12 秒；持续 45 秒低于约 30 KB/s 会判为低速，重试后仍失败才换源，不是 45 秒内一定换源。地址不支持续传才清掉半截重下，校验失败的文件也会删掉重下。全都不行，别让他去折腾网络设置，按上一条跳过这一项。
- **一项一项告诉他进度**：开始前说要下多大、大概多久；装好一项说一声。导入工具每块最后有一行 `RESULT <块>=ok|partial|fail|skip reason=… next=…`，照它转述，`next` 就是怎么补。
- **大件放后台**：几百 MB 以上的下载（表情包、本机语音模型、Ollama）用 `Start-Detached` 放后台跑、日志写进 `<工作目录>\logs\`，你每半分钟读一次日志转述进度，他可以一边等一边跟她聊。别把一个可能跑一个多小时的下载放在前台等，会被你自己的超时掐断。

## 验收（第 9 步）

依次让他做、你在后台日志里核对：

1. 大号私聊小号「在吗」→ 她回话，语气是大肥鱼（或他的角色）的。之前聊过的先发 `/reset`。
2. 选了群的：在群里 @ 她一句 → 她回。
3. 选了语音的：多聊几句，三条里大约有一条是语音（豆包要等 15–35 秒，Breeze 几秒）。
4. 表情包：多聊几句会配图；群里也会配（配置包 `7121c0c` 以后的版本才行）。
5. 选了记忆的：跟她说「记住，我家猫叫团子」，发 `/reset`，再问她「我家猫叫什么」。先跟他讲清楚记忆怎么存（别等他试失败了才说）：平时聊天攒满 10 轮（一问一答算一轮）她才总结一次存进长期记忆，没攒满就 `/reset` 再问，她多半不记得；想让她当场记住，就说「记住……」。10 轮是插件默认，想改在后台插件设置「总结触发轮次」里改（1–100）。
6. 私聊发一张图，问「图里是什么」；选了看视频的，再发一段 10–30 秒的视频（`看图看视频.md`「验收」）。
7. 掉线自救：选 A 的关掉 NapCat 窗口，双击桌面的「大肥鱼掉线-双击扫码」，能自己登回来（或弹码扫一下）；选 B 的双击桌面的「大肥鱼掉线-双击重登」（或在工作台点「重新登 QQ」）：它会把 SnowLuma 和桌面 QQ 重新打开，他在 QQ 窗口里点登录或扫码。

全部通过，跟他说一句完事了，再提醒几件事：DeepSeek Harness 的权限记得切回「工作区可写」；电脑开着她才在线；小号偶尔被 QQ 踢下线是正常的，桌面工作台里点一下就能重新登；选了本机语音或记忆的，打游戏前在工作台点「打游戏模式」，打完点恢复（`references/记忆.md`「对电脑的影响、打游戏」）；后台密码在 `<工作目录>\private\backend.txt`，想改成自己记得住的，改完把新密码写回这个文件。没装上的项，再说一遍怎么补。

## 装完以后他回来找你

- 「补装表情包、语音、记忆、看视频」：照「加功能的规矩」跑 `import-pack.ps1 -Only <那块>`（要下大文件的先跑对应的 install 脚本）。
- 「她不回话了」：先让他双击桌面的掉线自救，或者在工作台点修复；还不行再看日志。
- 「备份一下」「换电脑了」「重装系统前」「不想要了」「卸干净」：读 `references/备份、换电脑和卸载.md`。卸载一定先列清单、他回「确认」才删。

## 别做的事

- 不打开 AstrBot 的「操作电脑」能力，不给她执行命令、读写文件的工具。
- 不改系统代理、防火墙、网络设置（WorkBuddy 自己弹的防火墙框，点「取消」也不影响，10-25 实测）。
- SnowLuma：他没亲口说「同意」之前不加 `-AcceptAgreements`；不改 SnowLuma 包里的任何文件；不把它打包转给别人（它的协议不许）。
- 不帮他克隆别人的声音（游戏角色、配音演员、明星）。他自己的声音、或者用一句话捏出来的声音都行。
- 不把群里插话概率调到 0.1 以上，插得多容易被风控。
